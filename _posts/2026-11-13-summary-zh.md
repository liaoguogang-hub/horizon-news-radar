rss · Hacker News \(热门\) · 11月13日 21:06

**背景**: 机场地面停飞是一种交通管理措施；当目的地机场无法安全接收正常进场流量时，飞机可能被要求留在地面或禁止继续进场。此类措施可能由天气、空管人员不足、设备故障或其他运行限制引起，通常针对特定机场或区域，而非覆盖全国。联邦航空管理局的国家空域系统状态页面会公布正在实施的地面停飞、地面延误计划及其他空域事件。

## [Coway 空气净化器摆脱云端依赖](https://scottjg.com/posts/2026-11-11-reverse-engineering-my-coway-air-purifier-to-ditch-the-cloud/) ⭐️ 8.0/10

一名开发者逆向分析了 Coway Airmega IconS 空气净化器，并用本地控制取代了对其云服务的依赖，同时接入了 Home Assistant。该项目还发现了安全和工程设计缺陷，其中最突出的是风扇通过普通 HTTP 下载其根证书颁发机构证书。 当云服务不可靠时，本地控制可以维持设备功能，并减少通过厂商服务器传输设备数据所带来的隐私风险。这项工作还表明，逆向工程能够揭示实际的物联网安全问题，并推动更多项目让联网家电摆脱不必要的云端依赖。 研究者搭建了一个运行 mitmproxy 的中间人 Raspberry Pi 无线接入点，用于拦截净化器与 Coway IoCare 云服务之间的流量，并替换为自己的证书以分析通信协议。净化器通过普通 HTTP 传送证书，使流量拦截成为可能，也暴露了其信任与更新机制中本可避免的弱点。

hackernews · Hacker News \(热门\) · 11月12日 22:03 · [社区讨论](https://news.ycombinator.com/item?id=50474959)

**背景**: 许多联网家电依赖厂商云服务执行指令、报告状态、传送固件并接入智能家居平台。“去云化”项目通过逆向分析设备通信协议，再将其桥接到 Home Assistant 等本地系统，从而恢复这些功能。这种方式能够提高可用性和自主性，但也可能依赖非官方接口，并使设备面临额外安全风险。

文章提出了一套面向自托管 Dynatrace 集群的三层监控策略：检查 Cluster Management Console、核对各节点的系统资源与服务，并在集群之外监控基础设施。文章列出了磁盘、Cassandra、Elasticsearch、处理负载、备份和证书等具体检查信号，并给出了实用的命令行检查方法。 Dynatrace Managed 运行在客户自行管理的基础设施上，因此存储、网络、操作系统和备份可用性仍由运营团队负责。以对待关键业务服务的严格程度监控可观测性平台，可以降低平台自身故障造成监控数据缺口或导致无法恢复的风险。 关键指标包括每周磁盘增长量、Cassandra 延迟和待处理压缩、Elasticsearch 集群颜色与磁盘空间、服务器内存和 CPU、备份时效以及证书到期时间。文章建议使用 df、free、uptime、systemctl 和 journalctl 等命令进行每日检查，并部署独立于集群的带外监控层。

rss · Dev.to · 11月13日 21:30

**背景**: Dynatrace Managed 是一种由客户在自有基础设施上运行 Dynatrace 集群的部署模式，而非使用托管的 SaaS 服务。Managed 集群包含 Dynatrace Server、Cassandra、Elasticsearch、事务存储和 Web 前端等多个组件，任何一个组件都可能独立发生故障。Mission Control 可在集群保持必要连接时提供主动支持，但不会免除客户对底层基础设施的责任。

## [开源工具包让 AI 代理销售旅游 eSIM](https://dev.to/alexar76/selling-esims-to-ai-agents-the-sellers-side-tried-on-a-laptop-in-32-seconds-560d) ⭐️ 6.0/10

MIT 许可的 eSIM operator kit 新增一键试用模式，无需注册供应商账号、配置域名、部署服务器或提供 API 密钥，即可在笔记本上完整运行。作者在配备 32 GB 内存的 Apple M4 上测试，冷构建耗时 32 秒，缓存后启动仅需 6 秒，并通过本机端口提供商店界面和面向代理的卖家节点。 该更新降低了经销商和开发者测试 AI 代理如何查找、比价、购买和激活旅游 eSIM 的门槛，为数字通信产品提供机器可读的商务接口迈出了实用一步。不过，演示模式只使用虚构套餐，并不处理真实付款。 演示环境需要 Git 和较新的 Docker Compose，因为覆盖配置使用了旧版 Compose v2 无法解析的 \`\!reset\` 与 \`\!override\`。商店界面绑定 \`127.0.0.1:9495\`，卖家节点绑定 \`127.0.0.1:9490\`；系统提供 26 个国家的 49 个虚构套餐，状态仅存于 tmpfs，并验证报价格式、价格排序、Ed25519 签名、错误处理和 CORS。由于演示模式没有付款条款，x402 检查出现警告属于预期结果。
