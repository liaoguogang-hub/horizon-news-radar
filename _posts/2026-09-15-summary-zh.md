## [美国驾照数据泄露：一场国家安全危机](https://www.lawfaremedia.org/article/america%27s-drivers-licence-breach-is-a-national-security-disaster) ⭐️ 8.0/10

IDScan 公司发生重大数据泄露事件，多达 1.5 亿条美国和加拿大公民的驾照及政府身份证件记录被暴露。该事件被视为严重的国家安全威胁，其影响可与 2015 年导致联邦雇员敏感数据外泄的 OPM（美国人事管理局）泄露事件相提并论。 驾照数据是个人身份信息（PII）的核心组成部分，可被用于身份盗用、欺诈，甚至用于针对担任国家安全职务的个人。此次泄露事件规模庞大，波及绝大多数美国成年人，对数据保护标准以及处理敏感身份证件的供应商的企业问责制提出了紧迫的质疑。 IDScan 是一家为企业提供驾照验证服务的供应商，已确认发生泄露事件，但尚未向公众提供可供个人查询自身数据是否被泄露的工具。受影响的记录不仅包括驾照号码，还包括相关的个人信息，这进一步放大了后续欺诈行为的风险。

hackernews · Hacker News \(热门\) · 9月15日 15:58 · [社区讨论](https://news.ycombinator.com/item?id=49714547)

**背景**: 个人身份信息（PII）是指任何可用于识别特定个人身份的数据，而驾照数据是其中最敏感的形式之一，因为它通常是进行高信任度交易所必需的。2015 年的 OPM（美国人事管理局）数据泄露事件据信为中国国家级黑客所为，导致超过 2000 万联邦雇员及申请人的安全审查申请信息外泄，其中包括指纹数据，被广泛视为一场灾难性的情报损失。IDScan 作为第三方身份验证服务供应商，意味着众多依赖其服务的企业实际上已将数百万公民的敏感身份证件集中到一个单一故障点。

## [Baseten GitHub 组织因 Harbor 镜像仓库配置错误遭接管](https://www.strix.ai/blog/baseten-harbor-github-pat-takeover) ⭐️ 8.0/10

Strix 的安全研究人员在仅 25 分钟内，通过利用一个配置错误的 Harbor 容器镜像仓库来窃取有效的 GitHub Personal Access Token（PAT），从而获得了 Baseten 生产环境 GitHub 组织的完整管理员权限。该漏洞利用链从一个暴露在公网的 Harbor 实例一路升级到完整的 GitHub 组织接管，暴露了一个严重的供应链安全漏洞。 这个案例表明，一个配置错误的容器镜像仓库就可能导致组织源代码、CI/CD 流水线的全面失陷，甚至危及所有依赖该代码的客户。任何使用 Harbor 镜像仓库且存在硬编码或可泄露凭据的初创公司或企业，都面临着类似的供应链攻击风险。 此次攻击利用了 Harbor 镜像的标签或构建元数据来发现嵌入了管理员权限的 GitHub PAT，揭示了 CI/CD 构建上下文经常会将密钥泄露到容器镜像中。近期披露的 CVE-2026-4404（CVSS 评分 9.4）等漏洞表明，Harbor 中默认凭据和策略配置错误仍然是整个行业普遍存在的问题。

rss · Hacker News \(热门\) · 9月15日 18:11

**背景**: Harbor 是一个开源的企业级容器镜像仓库，常用于在云原生环境中存储和分发 Docker 镜像。它通常与 CI/CD 流水线集成，并经常包含用于拉取或推送镜像的凭据。GitHub Personal Access Token（PAT）是用于访问 GitHub 仓库和组织的身份验证凭据；如果一个拥有管理员权限的 PAT 泄露，攻击者就可以完全控制关联的 GitHub 组织，包括修改源代码、窃取密钥以及攻陷所有依赖该组织的软件构建。

## [Wayback Machine 因 AI 爬虫而实施速率限制](https://blog.archive.org/2026/09/15/an-update-on-wayback-machine-access/) ⭐️ 7.0/10

Internet Archive 解释说，对 Wayback Machine 实施严格的速率限制是为了应对大量来自 AI 爬虫的高频自动化流量——这些爬虫通过抓取网页的存档副本来绕过原站的访问限制。Archive 正在改进机器人检测机制，以更好地区分滥用流量与正常用户，并邀请用户通过邮件反馈被误封的情况。 这一事件凸显了 AI 公司对训练数据的巨大需求与公共网络基础设施保护之间日益加剧的矛盾。Wayback Machine 是研究人员、记者和公众使用的重要非营利资源，过度的速率限制可能会损害正常用户的体验，而 AI 爬虫却在无偿地持续攫取数据价值。 用户报告称，即使在正常使用操作（如浏览日历界面）时也会收到 HTTP 429（请求过多）错误，部分企业网络或机场 WiFi 甚至完全无法访问。Archive 指出，由于此类滥用行为，一些网站所有者已选择退出通过 Wayback Machine 抓取其内容，这进一步降低了该服务的实用性。

hackernews · Hacker News \(热门\) · 9月15日 17:52 · [社区讨论](https://news.ycombinator.com/item?id=49716176)

**背景**: Internet Archive 是由 Brewster Kahle 于 1996 年创立的非营利数字图书馆，其最知名的服务是 Wayback Machine，用于保存网页的历史快照。该服务的默认搜索 API 速率限制最近已降至约每分钟 24 次请求。越来越多的 AI 爬虫被发现绕过 robots.txt 协议（即发布者用来阻止自动爬虫的标准机制）来抓取内容以训练大语言模型，有时通过网页存档来绕过网站层面的封锁。

《柳叶刀》的一篇评论文章回顾了美国为同一品牌药物支付的价格比大多数欧洲国家高出三到五倍，并强调了特朗普政府试图利用国际参考定价来为 Medicare B 部分药品定价的做法。在其第一个任期内，特朗普总统曾指示 CMS 创新中心（CMMI）将 Medicare B 部分药品价格与国际价格挂钩。 国际参考定价可能通过使美国药品价格与其他高收入国家保持一致，从根本上重塑美国药品市场，有望降低 Medicare 和患者的费用，同时对全球制药公司的定价策略施加压力。这场政策辩论对制药企业、医疗服务提供者以及数百万依赖 Medicare B 部分获得临床用药的美国患者具有重大影响。 国际参考定价（IRP），又称外部参考定价，是一种国家主管部门通过跨国药品价格比较来确定本国药品价格的方法。CMS 创新中心（CMMI）的创建目的是在 Medicare、Medicaid 和儿童健康保险计划（CHIP）中测试新的支付和医疗服务模式，目标为降低支出或提高质量，但联邦评估显示其前 49 个模型中有许多未能实现持续的节省。

rss · The Lancet · 最新文章 · 9月13日 22:30

**背景**: Medicare B 部分涵盖在医生办公室和医院门诊环境中给药的药物，例如注射剂和输液，传统上 Medicare 按照平均销售价格加一定比例进行报销。国际参考定价在美国以外被广泛使用，但在国内具有政治争议性，因为它实际上可能从实行单一支付方或国有化医疗体系的国家引入价格管制。制药企业更广泛的担忧是，美国向较低的国外价格看齐可能会减少全球收入并抑制制药研发投入。
