## [Attackers Forged Admin Sessions on Check Point Management Servers](https://www.greynoise.io/blog/check-point-security-management-servers-intrusion-campaign) ⭐️ 8.0/10

Attackers exploited predictable output from JavaScript&\#x27;s Math.random\(\) in Check Point management-server session cookies to reconstruct the V8 PRNG state and recover the session-cookie signing key. They then used the key to forge administrator session cookies and actively targeted exposed management servers. A forged administrator session can provide high-privilege access to sensitive security-management systems, potentially enabling compromise of many downstream resources. The incident demonstrates how using a non-cryptographic PRNG for security-sensitive key material can turn observable application behavior into an authentication bypass. The reported attack repeatedly accessed the HFS loginSrp1 endpoint and collected signed cookies whose sid values exposed outputs from the same V8 PRNG used to derive the signing key. Remediation should replace Math.random\(\) with a cryptographically secure generator such as Node.js crypto.randomBytes\(\), rotate affected signing keys, invalidate existing sessions, and restrict management-server exposure.

hackernews · Hacker News \(热门\) · Nov 24, 16:32 · [Discussion](https://news.ycombinator.com/item?id=50630594)

**Background**: Session-cookie signing keys allow a server to verify that session data was issued by the server and has not been modified. JavaScript&\#x27;s Math.random\(\) is designed for general-purpose randomness rather than cryptographic security, while V8 is Google&\#x27;s JavaScript and WebAssembly engine used by Node.js. The related Rejetto HFS vulnerability is identified as CVE-2026-61500 and affects versions before 3.2.1.

**Background**: A deterministic system follows the same sequence of states for the same input, while a deterministic VM can enforce repeatable execution for testing and analysis. Conventional profilers and flame graphs reveal sampled runtime activity but may obscure relationships among threads and event handlers, particularly in asynchronous systems.
