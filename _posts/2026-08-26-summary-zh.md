## [AWS 收购 DuckLabs，DuckDB 开源项目不受影响](https://ducklabs.com/news/2026/08/26/ducklabs-to-join-aws) ⭐️ 8.0/10

AWS 收购了 DuckLabs，这家从荷兰 CWI 研究所分拆出来的商业公司，提供围绕 DuckDB 生态系统的商业服务，包括 MotherDuck 托管云产品。而开源的 DuckDB 项目本身以及 DuckLake、Quack 等相关项目，仍由独立的非营利性 DuckDB 基金会管理，继续遵循 MIT 许可证，路线图和治理模式均保持不变。 DuckDB 是增长最快的开源分析型数据库之一，被数据科学家和工程师广泛用于进程内分析。AWS 收购其商业部门，标志 AWS 服务将更深入地集成 DuckDB 技术，有望加速其普及，但也引发了人们对这一广受喜爱的社区项目长期管理归属的担忧。 DuckDB 基金会持有该开源项目的知识产权，资金来源于慈善捐赠而非外部投资者。DuckLabs 此前从荷兰国家数学与计算机科学研究中心 CWI（Centrum Wiskunde &amp; Informatica）分拆而出，该基金会正是当时专门为保护项目独立性而设立的。

hackernews · Hacker News \(热门\) · 8月26日 12:59 · [社区讨论](https://news.ycombinator.com/item?id=49448321)

**背景**: DuckDB 是一个进程内 SQL OLAP（在线分析处理）数据库，即它作为嵌入式组件运行在应用程序内部，而非作为独立的服务器。它以快速的列式存储引擎和支持超出内存容量的大规模工作负载而闻名。CWI 阿姆斯特丹是荷兰国家数学与计算机科学研究中心，DuckDB 最初就是在这里开发的。DuckDB 基金会作为一个非营利性治理机构成立，旨在确保该开源项目不依赖于任何单一商业实体——在本次收购的背景下，这一治理结构变得至关重要。

## [OpenAI Jalapeño 芯片在 InferenceX 基准测试中夺冠](https://techcrunch.com/2026/08/25/openais-jalapeno-chip-is-built-for-fast-inference-at-scale-benchmarks-show/) ⭐️ 8.0/10

OpenAI 自研的 Jalapeño 推理芯片在 SemiAnalysis InferenceX 基准测试中取得了业界领先的成绩，在单用户吞吐量（tokens-per-user）和每千瓦吞吐量（throughput-per-kilowatt）两项指标上均超越了现有的顶级硬件。这一成绩使 Jalapeño 成为大规模大语言模型服务负载下的领先加速器。 这一里程碑标志着 OpenAI 凭借一款专为推理打造的芯片正式进入自研 AI 芯片市场，有望降低其对 NVIDIA GPU 的依赖，并改变前沿模型大规模服务的经济结构。同时，这也加剧了 OpenAI 与 NVIDIA、AMD 以及 Google TPU 项目在快速增长的人工智能基础设施市场上的竞争。 该基准测试由独立的 SemiAnalysis InferenceX 平台执行，该平台提供开放、供应商中立、可复现的加速器性能测量，涵盖 NVIDIA GB200/B200、AMD MI355X 和 GB300 NVL72 等系统。InferenceX 评估的是真实场景下的智能体工作负载，例如多步工具调用和编程智能体，而非仅仅是单用户延迟，因此其每千瓦吞吐量指标对于数据中心级部署尤为关键。

rss · TechCrunch AI · 8月25日 14:22

**背景**: 大语言模型推理基准测试传统上衡量的是单个用户访问独立端点的表现，但真实的生产环境服务需要高效处理大量并发用户。单用户令牌生成速度（tokens-per-user）和每千瓦吞吐量（throughput-per-kilowatt）等指标对于在互联网规模上运行 GPT 或 DeepSeek 等模型的大型云服务商至关重要。SemiAnalysis InferenceX 是一个开源的持续基准测试平台，可在真实智能体和编程工作负载下比较 NVIDIA GB200 NVL72、AMD MI355X、B200 以及 Google TPU 等加速器。OpenAI 的 Jalapeño 属于定制 AI 芯片浪潮的一部分（与 Google TPU、Amazon Trainium 等并列），旨在优化 NVIDIA 主导 GPU 体系之外的推理经济性。

## [实验室供应商使用篡改图片销售抗体](https://arstechnica.com/science/2026/08/lab-supply-companies-have-been-selling-antibodies-using-manipulated-images/) ⭐️ 8.0/10

一项调查揭露，实验室供应商经常使用数字篡改的图片来推销抗体产品。这种做法若出现在学术论文中将导致撤稿，但在商业产品图片中却普遍存在。 抗体是几乎所有生物医学研究的基础工具，不可靠的试剂是生命科学领域可重复性危机的重要根源。这一发现表明，不可重复性研究的主要源头并非个别实验室，而是商业供应链本身，这影响了大量下游研究。 《细胞生物学杂志》等期刊长期以来对图像处理执行严格标准，使用专用软件审查投稿，并将不当调整作为撤稿依据。这项调查揭示了一个明显的双重标准：在已发表论文中会招致处罚的做法，在试剂供应商的营销行为中却司空见惯。

rss · Ars Technica · 8月25日 16:16

**背景**: 抗体是研究人员在蛋白质印迹、免疫组化和流式细胞术等实验中用来检测特定分子靶标的蛋白质，其特异性对实验结果的有效性至关重要。生物医学研究界长期面临可重复性危机，据估计超过三分之一不可重复的临床前研究可追溯到试剂质量问题，包括验证不足的抗体。科研中的图像篡改——从拼接条带到过度调整对比度——一直是一个被广泛记录的问题，促使期刊制定正式的指南和审查工具，以确保发表的图表能准确反映原始数据。

## [实证研究发现 LLM 智能体技能在执行过程中泄露凭据](https://arxiv.org/abs/2604.03070) ⭐️ 6.0/10

一项新的实证研究审计了 17,022 个 LLM 智能体技能，发现其中约 3.1% 在正常执行过程中会泄露 API 密钥和密码等凭据。该论文研究了集成在基于 LLM 的智能体中的工具和技能如何意外暴露敏感的身份验证数据。 随着 LLM 智能体越来越多地获得对外部工具、API 和服务的访问权限，智能体技能的凭据泄露代表了一个重大且未被充分审视的攻击面。即使在常规执行过程中（而不只是对抗性场景下），智能体也可能泄露密钥，使开发者、组织和最终用户面临数据泄露和未授权访问的风险。 该研究检查了 17,022 个智能体技能，其中 3.1% 在正常（非恶意）执行流程中被发现泄露凭据，包括 API 密钥和密码。该论文可在 arXiv 上获取（ID 2604.03070），但具体受影响的技能、泄露途径和修复策略需要阅读完整论文才能了解。

rss · Hacker News \(AI/ML\) · 8月26日 18:21

**背景**: LLM 智能体通过“技能”（skills）或“工具”（tools）来扩展大语言模型的能力——这些专门模块（通常定义在 SKILL.md 文件中）允许模型执行调用 API、查询数据库或运行代码等操作。当智能体运行时，它通过推理、工具选择和执行步骤的循环来自主完成任务。由于这些技能通常需要 API 密钥或 OAuth 令牌等凭据才能运行，它们处理和传输这些密钥的方式成为一个关键的安全问题。OWASP Agentic Top 10 已将与工具相关的风险列为 AI 智能体部署的关键威胁类别。
