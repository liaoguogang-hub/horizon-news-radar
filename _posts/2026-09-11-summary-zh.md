## [WebGPU 漏洞可使 macOS 通过恶意网站宕机](https://auberon.xyz/blog/posts/deathray/) ⭐️ 8.0/10

WebGPU 中发现了一个安全漏洞，攻击者只需让用户在浏览器中访问一个不受信任的网站，即可使 macOS 系统完全冻结。该攻击利用了较新的浏览器 GPU API，在受影响的 Mac 上触发拒绝服务（DoS）条件。 这个漏洞意义重大，因为它暴露了一个新兴浏览器 API 中的新型攻击向量，表明即使是现代 Web 标准也可能引入严重的安全风险。它揭示了浏览器沙箱机制的缺陷，并引发了对将 GPU 等底层硬件能力直接暴露给网页内容的担忧。 该漏洞利用仅要求用户访问恶意网页——除页面加载外不需要任何用户交互即可触发系统冻结。该问题似乎是 macOS 平台特有的，表明底层 Metal 驱动或其与 WebGPU 的集成可能是根源，而非跨平台缺陷。

rss · Lobsters \(技术社区\) · 9月11日 00:04

**背景**: WebGPU 是一个相对较新的 Web 标准，由 W3C 制定，通过 JavaScript API 向 Web 应用暴露现代 GPU 的硬件能力。它映射到各平台的原生图形 API：macOS 上的 Metal、Linux 和 Android 上的 Vulkan、Windows 上的 Direct3D 12。WebGPU 通过将底层 GPU 资源直接暴露给网页，使得浏览器能够运行高性能图形、游戏和机器学习任务，但这种扩展访问也扩大了潜在的攻击面。拒绝服务（DoS）漏洞会使系统失去响应能力，基于浏览器的 DoS 攻击在 macOS 上由来已久，包括过去 Safari 在访问特定构造的网页时崩溃的案例。

## [CHERIoT：无 MMU 微控制器的基于能力的安全隔离方案](https://queue.acm.org/doi/10.1145/3831361) ⭐️ 8.0/10

ACM Queue 发表文章，详细介绍了 CHERIoT 如何利用硬件能力（capability）特性，在缺乏传统内存管理单元（MMU）的微控制器级别设备上实现强力的内存隔离和分舱化（compartmentalization）。这一源自微软研究的架构，通过硬件强制的能力机制而非虚拟内存，直接实现细粒度的软件分舱化。 这一点至关重要，因为嵌入式和物联网设备通常缺乏 MMU，却面临着日益严峻的安全威胁，而 CHERIoT 为这些资源受限的平台提供了一条实现内存安全与分舱化的实用路径。它有望显著降低工业、汽车和消费物联网系统中的攻击面——在这些领域，软件漏洞已经造成了巨大的现实危害。 CHERIoT 构建于 RISC-V Ibex 核心之上，在 RV32EMCB 指令集的基础上增加了能力扩展。为适应微控制器的资源限制，它采用了紧凑的 65 位能力格式，而非大型 CHERI 实现中使用的 129 位能力，并且强制要求能力偏移量始终为非负值以简化元数据处理。该技术已进入商业化阶段，SCI Semiconductor 已于 2024 年发布了兼容 CHERIoT 的 ICENI 微控制器。

rss · Lobsters \(技术社区\) · 9月10日 14:59

**背景**: 内存管理单元（MMU）是通常负责将虚拟内存地址转换为物理地址并强制进程隔离的硬件组件，但其体积、功耗和成本对于低端微控制器应用场景来说过于庞大。CHERI（Capability Hardware Enhanced RISC Instructions，能力硬件增强 RISC 指令）是由 SRI International 和剑桥大学开发的一种研究性架构，采用了不同的思路：它引入了不可伪造的硬件能力（capability），将指针及其关联的权限和边界一起编码，从而在每一次内存访问时实现细粒度的内存保护。CHERIoT 是 CHERI 针对微控制器级别设备的专门化版本，特别注重芯片面积、功耗和内存占用等约束条件。

## [美国阿片类药物危机连续第三年出现用药过量死亡人数下降](https://www.thelancet.com/journals/lancet/article/PIIS0140-6736%2826%2901610-7/fulltext?rss=yes) ⭐️ 6.0/10

根据美国疾病控制与预防中心（CDC）的临时估计，2025 年美国约有 7 万人因药物过量死亡，较 2024 年下降近 14%，这是连续第三年下降，从 2022 年约 10.8 万人的峰值回落。几乎每个州报告的 2025 年用药过量死亡人数都比前一年有所减少。 在经历了十多年死亡人数持续上升之后，这一持续且覆盖广泛的逆转表明，政策干预、纳洛酮和药物辅助治疗等治疗手段的可及性扩大，以及非法药物供应的变化，可能正在有效遏制这场危机。这一趋势对美国公共卫生政策、医疗成本具有重大意义，也可为面临类似问题的其他国家提供借鉴。 这些数据是 CDC 的临时估计值而非最终死亡数据，由于死亡证明处理和 ICD-10 编码的滞后，用药过量死亡通常在死亡日期六个月后才公布。CDC 同时发布每月临时计数和基于模型的季度临时死亡率估计，2025 年的数据仍有修订可能。

rss · The Lancet · 最新文章 · 9月9日 22:30

**背景**: 美国阿片类药物危机大致经历了三个阶段：1990 年代末由处方阿片类止痛药推动的第一波、2010 年前后由海洛因推动的第二波，以及 2013 年左右开始由非法芬太尼和其他合成阿片类药物主导的第三波。这一进程涉及普渡制药和萨克勒家族等重要主体，并促使联邦政策做出应对，包括扩大纳洛酮（一种阿片类药物过量逆转药物）的可及性、推行药物辅助治疗以及建立处方监测项目。CDC 的临时估计是基于模型的预测，比最终死亡证明数据更早提供信号，而最终数据的编制可能需要一年多时间。
