## [AI 辅助的零点击蠕虫通过微信通话在 iOS 和 Android 上传播](https://simonwillison.net/2026/Sep/10/calif-research/) ⭐️ 9.0/10

Calif Research 公开演示了 WeWorm，这是首个通过微信语音通话在 iOS 和 Android 上跨平台传播的零点击蠕虫，攻击者无需任何用户交互即可劫持账户。在 AI 辅助下，团队在大约两天内找到了底层漏洞并编写了初始远程代码执行漏洞利用程序，再花约一周时间完成了完整蠕虫的构建。 微信拥有超过十亿用户，这使得此类漏洞利用对移动安全和个人隐私构成巨大潜在威胁，尤其考虑到入侵完全不需要用户操作。从传统团队需要数月到借助 AI 只需数天的开发时间大幅压缩，标志着 AI 增强的攻击性网络能力出现重大升级，也对 AI 安全社区提出了关于生成式 AI 在安全研究中双重用途风险的紧迫问题。 受害者无需接听来电，即使接听也听不到任何声音，漏洞利用在后台静默执行。该蠕虫利用了微信自定义浏览器组件中的漏洞（与 Talos 此前记录的 XWalk 运行时相关），据报道腾讯在收到私下披露后已封堵了该漏洞。Calif 强调，人类提供了关于攻击目标和安全测试的策略判断，而 AI 承担了大部分技术漏洞利用工作。

rss · Simon Willison \(AI 跨行业洞察\) · 9月10日 00:56

**背景**: 零点击漏洞利用是一种不需要受害者任何交互——无需点击、打开链接或接听——的利用方式，因此尤其危险，因为用户无法采取任何行动来避免。蠕虫是一种自我传播的恶意软件，会从一台受感染设备自动扩散到其他设备（在本例中是受害者的微信联系人）。远程代码执行（RCE）意味着攻击者可以在受害者设备上运行任意代码，可能读取消息、拨打电话或发起进一步的链式攻击。微信由腾讯运营，是全球最大的消息平台之一，在中国和整个亚洲渗透率极高，这放大了任何影响它的漏洞的影响范围。AI 辅助漏洞利用开发是指利用大语言模型加速漏洞发现、逆向工程和漏洞利用编写的新兴做法——这些任务此前需要专业人类专家耗费大量时间。

## [Forgejo 16.0.4 发布，修复严重远程代码执行漏洞](https://codeberg.org/forgejo/forgejo/src/branch/forgejo/release-notes-published/16.0.4.md) ⭐️ 8.0/10

Forgejo 发布了 16.0.4 版本，其中包含一个针对该自托管 Git 平台中远程代码执行（RCE）漏洞的关键安全补丁。 RCE 漏洞是最严重的安全问题之一，攻击者可以利用它在主机系统上执行任意代码，并可能实现完全控制。任何自托管 Forgejo 的组织或个人都应优先立即升级，以保护其源代码仓库和底层基础设施。 该漏洞使远程攻击者能够在托管 Forgejo 的服务器上执行恶意代码。建议用户立即更新到 16.0.4 版本；所提供的内容中未披露该漏洞利用途径的具体技术细节。

rss · Lobsters \(技术社区\) · 9月10日 17:40

**背景**: Forgejo 是一个自托管、轻量级的 Git 平台，从 Gitea 分叉而来，由 Codeberg e.V. 非营利组织下的社区维护。它允许用户托管自己的 Git 仓库，完全掌控源代码和数据，因此在寻求摆脱第三方平台依赖的组织中颇受欢迎。远程代码执行漏洞是一种代码注入攻击，攻击者可以攻陷远程服务器并运行任意命令，通常发生在用户数据与可执行指令之间的边界未得到正确区分时。这类漏洞可能导致系统被完全接管、数据泄露以及在网络内部进行横向移动。

## [Shopify 从 React Native 回归原生 Swift/Kotlin 开发](https://simonwillison.net/2026/Sep/10/shopify-react-native/) ⭐️ 8.0/10

Shopify 宣布将其移动应用从 React Native 迁移回独立的原生 Swift（iOS）和 Kotlin（Android）代码库，推翻了其 2020 年的决定。公司表示，AI 编程智能体在实现、转换、测试和代码审查方面的能力，使得维护两个独立代码库的成本不再是决定性因素。 这是 React Native 最著名的采用者之一的一次高调转向，并为 AI 编程工具已经在重塑基础技术战略决策提供了有力证据。此举向整个移动开发生态系统发出了信号：随着 AI 智能体降低了原生开发的开销，有利于跨平台框架的传统权衡可能会被削弱。 Shopify 维护着三个重要的 React Native 库：react-native-skia 和 flash-list 正在移交给新的维护者，而用户基础较小的 restyle 将于 2026 年底归档。Shopify 在 2020 年选择 React Native 的初衷是避免重复开发相同功能、实现跨技术栈的开发者协作以及减少追求功能一致性的时间——而这些问题现在可以通过 AI 智能体大幅缓解。

rss · Simon Willison \(AI 跨行业洞察\) · 9月10日 21:11

**背景**: React Native 是一个由 Meta 最初开发的开源移动框架，允许开发者使用 JavaScript 和 React 构建 Android 和 iOS 应用，而无需分别维护 Swift（iOS）和 Kotlin（Android）的独立原生代码库。React Native 和 Flutter 等跨平台框架因能减少重复工作和开发成本而广受欢迎，但通常以牺牲平台特定性能和集成为代价。Cursor、Replit Agent 和 CodeGPT 等 AI 编程智能体代表了一类较新的工具，能够跨多种语言和平台自主编写、转换、测试和审查代码。
