## [Claude Code Opus 5 Auto Mode Bypassed via Python Module Shadowing](https://embracethered.com/blog/posts/2026/breaking-claude-code-opus-5-and-automode/) ⭐️ 8.0/10

Security researcher demonstrated an attack against Claude Code Opus 5&\#x27;s auto mode where a malicious zip archive containing a shadow Python module \(struct.py\) overrides the standard library&\#x27;s base64 decoder, allowing code execution that bypasses the Sonnet 4.6 classifier-based safety review. Although Claude detects the compromise, auto mode blocks its cleanup command, turning the safety mechanism itself into part of the failure. This reveals a fundamental architectural weakness in AI coding agents that run code in attacker-controlled directories: deterministic model behaviors \(like consistently reaching for \`python -c\` or specific tools\) become predictable attack surfaces that adversaries can exploit at scale. The research underscores that without proper sandboxing and network restrictions, auto-mode agents handling untrusted code represent a significant supply-chain and code-execution risk. The exploit leverages Python&\#x27;s module search path placing the current working directory before standard library locations, causing \`base64\` to import the attacker&\#x27;s \`struct.py\` instead of the stdlib version. Notably, the attack isn&\#x27;t strictly prompt injection since it doesn&\#x27;t hijack agent instructions but instead deceives Claude through filesystem manipulation — better classified as a targeted trojan against predictable model behavior.

hackernews · Hacker News \(热门\) · Aug 31, 07:49 · [Discussion](https://news.ycombinator.com/item?id=49506819)

**Background**: Claude Code&\#x27;s auto mode uses a separate classifier model \(Sonnet 4.6\) to review and approve or block agent actions before execution, functioning as an automated safety layer. Python module shadowing occurs when a local file shares the name of a standard library module and is imported due to Python&\#x27;s directory search order \(cwd preceding stdlib\). Prompt injection is a class of attack where adversarial text in inputs manipulates LLM behavior, distinct here because the attack exploits execution context rather than language model instructions.

## [Discontinuing Beta-Blockers Safe for Stable Post-MI Patients: Pooled Trial Analysis](https://www.thelancet.com/journals/lancet/article/PIIS0140-6736%2826%2901426-1/fulltext?rss=yes) ⭐️ 8.0/10

A pooled individual patient data analysis of the ABYSS and SMART-DECISION trials, published in The Lancet, demonstrates that discontinuing beta-blockers is non-inferior to continuation in stable post-myocardial infarction \(MI\) patients with left ventricular ejection fraction \(LVEF\) ≥40% and no heart failure. This finding challenges the long-standing practice of indefinite beta-blocker prescription after MI, which has been a cornerstone of post-infarction care for decades. If adopted into guidelines, it could spare millions of stable patients globally from unnecessary medication burden, side effects, and costs. The study used a non-inferiority trial design to establish that discontinuation was not meaningfully worse than continuation for primary and key secondary endpoints. However, the authors note that interpretation of the primary endpoint is limited by its composition being heavily weighted toward hospitalisations and its variability across trials.

rss · The Lancet · 最新文章 · Aug 30, 07:30

**Background**: Beta-blockers are medications that reduce heart rate and blood pressure, and they have been routinely prescribed to patients after a myocardial infarction \(heart attack\) based on older clinical trial evidence from an era before modern reperfusion therapies \(such as stenting\) became standard. Left ventricular ejection fraction \(LVEF\) measures the percentage of blood the left ventricle pumps out with each contraction; a value ≥40% is considered preserved and indicates reasonably good heart pump function. A non-inferiority trial design is used when the goal is to show that a new treatment \(in this case, discontinuation\) is not unacceptably worse than the standard treatment \(continuation\), which is particularly relevant when the new strategy offers other benefits such as reduced side effects or cost.

## [C++26: Standard Library Hardening Experiments](https://www.cppstories.com/2026/hardening-experiments/) ⭐️ 7.0/10

The article provides an overview of C++26 proposals focused on hardening the standard library by converting certain instances of undefined behavior into detectable, terminating contract violations at runtime. These efforts are formalized through papers such as P3471R4 and represent the first practical use of the C++ contracts facility \(P2900\). Memory safety and undefined behavior are among the most critical and persistent sources of bugs and security vulnerabilities in C++ software, affecting millions of systems-level developers. Hardening the standard library provides a standardized baseline that shifts dangerous silent failures into detectable crashes, making C++ code safer to debug and more resilient in production. Hardening specifically targets common and dangerous Standard Library precondition violations, turning them into guaranteed program termination before any other observable side effects. The feature has been accepted for C++26 at the Austrian WG21 meeting and is considered more advanced than earlier profile-based safety approaches.

rss · Lobsters \(技术社区\) · Aug 31, 17:52

**Background**: In C++, many standard library functions have preconditions that, if violated by the caller, result in undefined behavior — meaning the program may behave unpredictably, silently corrupt data, or crash far from the actual bug. This makes such bugs extremely difficult to diagnose. The proposed hardening mechanism introduces a uniform way for standard library implementations to detect these precondition violations at runtime and terminate the program in a controlled manner. It builds on the broader C++ contracts proposal \(P2900\), which provides the language-level machinery for expressing and checking preconditions, postconditions, and assertions.

## [Tencent Releases Hy4 Preview: 770B Open-Weight LLM with 1M Context](https://simonwillison.net/2026/Aug/29/hy4/) ⭐️ 7.0/10

Tencent has released Hy4 Preview, a new open-weight text-only LLM with 770B total parameters, 49B active parameters, and a 1M token context window, distributed as a 1.56TB download on Hugging Face. This represents a substantial size increase from the previous Hy3 model released in July, which had 295B total / 21B active parameters, 256K context, and a 598GB weight footprint. Hy4 Preview is one of the largest openly available open-weight LLMs, joining a small group of Chinese-developed models pushing toward frontier-scale parameters with long-context capability. The combination of MoE efficiency \(only 49B active\) and a 1M token window makes it competitive for long-document tasks, though the absence of vision and published benchmarks tempers expectations. rss · Simon Willison \(AI 跨行业洞察\) · Aug 29, 23:53

**Background**: Hy4 is part of Tencent&\#x27;s Hunyuan \(混元\) LLM family, first announced in September 2023 as a proprietary dense model with over 100B parameters. A security researcher discovered nine vulnerabilities affecting ATM encryption and authentication software, uncovering weaknesses that extend well beyond standalone cash machines. The findings, reported by WIRED, have been documented as nine CVEs targeting critical security layers in ATM systems. These vulnerabilities highlight systemic weaknesses in how security-critical software is developed, integrated, and maintained across the software supply chain. Financial institutions, security vendors, and any organization relying on similar cryptographic and authentication libraries could face cascading risks if foundational components are compromised. The nine CVEs target encryption and authentication mechanisms — the very systems designed to protect financial transactions and sensitive data. The researcher emphasized that the implications go beyond ATMs, as the same flawed patterns likely exist in other enterprise and embedded systems that share similar software dependencies.

**Background**: ATMs rely on layered encryption and authentication software to protect cash dispensing operations, cardholder data, and network communications. Software supply chain security refers to the practice of ensuring that all components — including third-party libraries, vendor updates, and integrated tools — are free from vulnerabilities and tampering. When foundational security libraries contain flaws, the consequences can ripple through thousands of deployed devices, as illustrated by past ATM heists where attackers stole millions within minutes.

## [Rethinking Long-Term β-Blocker Use After Myocardial Infarction](https://www.thelancet.com/journals/lancet/article/PIIS0140-6736%2826%2901650-8/fulltext?rss=yes) ⭐️ 6.0/10

A Lancet commentary questions whether routine, indefinite β-blocker therapy remains justified for contemporary post-myocardial infarction \(MI\) patients, given that the foundational trials from the early 1980s were conducted before modern reperfusion, invasive management, statins, and dual antiplatelet therapy became standard care. If long-term β-blocker therapy proves no longer necessary in the modern era, it would change prescribing practice for millions of MI survivors worldwide, reducing medication burden, side effects, and costs; conversely, if the drugs remain beneficial, the commentary underscores the need for new randomized evidence to confirm contemporary efficacy. The commentary highlights that decades-old β-blocker trials predated four pillars of contemporary MI care—routine reperfusion, invasive management, statins, and dual antiplatelet therapy—making extrapolation to today&\#x27;s patients uncertain. It is a commentary rather than original research, so it signals a clinical question rather than providing definitive trial data.

**Background**: β受体阻滞剂是一类通过阻断β肾上腺素能受体来减弱交感神经激活对心脏影响的药物，常用于控制心律失常及心肌梗死后的二级预防。心肌梗死（心脏病发作）的治疗已被再灌注治疗（通过溶栓或经皮冠状动脉介入恢复血流）、他汀类降脂药物和双联抗血小板治疗（通常为阿司匹林联合P2Y12抑制剂以预防支架血栓和再发事件）彻底改变。由于这些现代治疗已显著降低心肌梗死后的死亡率，在再灌注时代前确立的长期β受体阻滞剂带来的额外获益必须被重新评估。
