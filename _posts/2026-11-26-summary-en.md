## [Nfs2root Enables Pre-Authentication Remote Root on Linux NFS Servers](https://opensec.in/blog/nfs2root-cve-2026-99362) ⭐️ 10.0/10

OpenSec disclosed CVE-2026-99362, a 12-year-old heap overflow in the Linux kernel’s NFS server, and demonstrated how an unauthenticated client can corrupt kernel memory and obtain root access. The flaw reportedly affects Linux systems running the in-kernel NFS server with NFSv4.1 or NFSv4.2 support, and a patch has been issued. A reachable NFS server on TCP port 2049 could allow a remote attacker to take over the host without credentials or user interaction. Because the vulnerability is reportedly present since Linux 3.16 and has a published exploit, exposed systems face an urgent patching and exposure-assessment requirement. The reported attack path is a pre-authentication heap overflow that writes 61 bytes beyond a kernel heap object, leading to kernel-memory corruption and a root shell. Exploitation is associated with a single TCP connection to the NFS server, and a Zeek package is available to monitor NFS traffic for exploitation attempts.

rss · Hacker News \(热门\) · Nov 25, 20:35

**Background**: NFS, or Network File System, lets clients access files and directories exported by a server. The affected component is nfsd, the in-kernel NFS server implemented within the Linux kernel, rather than a separate userspace daemon. A pre-authentication memory-corruption flaw is especially serious because the attacker does not need a valid account and can cross the normal boundary between an NFS client request and privileged kernel execution.

## [Polynomial Hirsch Conjecture Disproved for Simple Polytopes](https://github.com/openai/math/blob/main/preprints/Superpolynomial-graph-diameter-of-simple-polytopes-November-24-2026/paper.pdf) ⭐️ 8.0/10

The paper shows that simple polytopes can have graph diameters growing superpolynomially, disproving the polynomial version of the Hirsch conjecture. It also rules out any simplex algorithm that provably runs in polynomial time on all linear programs. The result clarifies a fundamental limitation of geometric pivot methods for linear programming and explains why the simplex method’s strong practical performance does not imply a polynomial worst-case guarantee. It may redirect research toward algorithms with different guarantees, including polynomial-time interior-point methods. The Hirsch conjecture proposed that the graph of an n-facet, d-dimensional polytope has diameter at most n−d; because a simplex pivot moves along an edge, this bound would support a polynomial worst-case step count. A related original conjecture was already disproved in 2010, so the new result is best understood as settling the remaining polynomial version for simple polytopes.

hackernews · Hacker News \(热门\) · Nov 25, 17:34 · [Discussion](https://news.ycombinator.com/item?id=50644980)

**Background**: A linear program defines a feasible region that is a polyhedron; when bounded, it is a polytope, whose vertices correspond to basic feasible solutions. The simplex method moves between such vertices along edges, so the diameter of the polytope’s graph gives a lower bound on the number of pivots required by this approach. The Hirsch conjecture, proposed in 1957, sought a bound that would explain the simplex method’s practical speed through a polynomial worst-case guarantee.
