## [AliExpress 利用 WebAudio 静默指纹追踪，干扰蓝牙多点连接](https://blog.laserphile.com/2026/08/aliexpress-webpage-keeping-multipoint.html) ⭐️ 8.0/10

一位安全研究人员发现，AliExpress 网站运行静默的 WebAudio 指纹追踪代码，会产生人耳无法听到的声音，从而干扰蓝牙多点连接并导致音频设备异常。 这表明一个大型电商平台正在部署一种隐蔽的、无需权限的追踪技术，不仅侵犯隐私，还对用户硬件产生了实际副作用。它揭示了浏览器安全模型（将音频播放视为良性行为）与高流量网站实际滥用行为之间的差距。 WebAudio 指纹追踪的工作原理是通过 Web Audio API 生成音频信号，并测量浏览器/硬件对其的处理方式，从而生成一个稳定且相对唯一的标识符，且无需任何用户授权。其副作用是这些静默信号会通过操作系统音频栈路由到已配对的蓝牙设备，干扰多点握手，导致助听器和车载音频系统出现异常行为。

hackernews · Hacker News \(热门\) · 8月20日 10:08 · [社区讨论](https://news.ycombinator.com/item?id=49372583)

**背景**: 浏览器指纹追踪是一种通过将硬件和软件属性（如 GPU、字体、屏幕尺寸和音频处理行为）组合成唯一签名来识别用户的技术，无需使用 Cookie。WebAudio API 指纹追踪变体尤其隐蔽，因为它不需要麦克风权限，且在后台静默运行。蓝牙多点连接是一项允许单个耳机或助听器同时与两个源设备（如手机和笔记本电脑）保持连接的功能，因此对意外的音频路由事件非常敏感。

Modular 公司已将 Mojo 编译器及工具链以 Apache 2 许可证开源，兑现了早在 2023 年 5 月许下的承诺。此次发布紧随上周 Mojo 达到 1.0 里程碑之后，而且该语言已正式偏离了最初作为完整 Python 超集的设计目标。 Mojo 旨在通过借鉴类 Python 的语法让 GPU 编程和高性能 AI 计算变得更加容易上手，而开源降低了社区贡献和采用的门槛。同时，放弃严格 Python 超集的定位也体现了务实的态度——承认 AI 辅助编程工具可以处理代码迁移，从而重塑了语言在大语言模型时代的演进方式。 Mojo 保留了类 Python 的语法，但融合了借鉴自 Rust 的系统级语言语义，包括静态类型检查和借用检查器。Apache 2 许可证完全宽松，允许商业使用，该项目目前面向 Linux 和 macOS 平台。

rss · Simon Willison \(AI 跨行业洞察\) · 8月18日 21:39

**背景**: Mojo 由 Modular 公司开发，该公司构建了一个统一的 AI 执行引擎，旨在加速 GPU 等异构硬件上的 AI 工作负载。该语言于 2023 年首次发布，目标是成为 Python 的严格超集，使现有 Python 代码无需修改即可在 Mojo 中运行。它的设计融合了 C++ 和 Rust 等系统级语言的性能特性，以及 Python 的可读性。最近的路线图更新放弃了严格超集的要求，并指出 AI 辅助工具可以作为迁移 Python 代码的桥梁。
