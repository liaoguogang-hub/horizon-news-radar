## [BTR: New Spectre-v2 Attack Targets JIT Compilation Engines](https://www.vusec.net/projects/btr/) ⭐️ 8.0/10

VUSec researchers have disclosed Branch Target Reuse \(BTR\), a new Spectre-v2 variant that exploits stale indirect branch prediction entries in JIT compilation engines to achieve a speculative execute-after-free primitive. When JIT engines repopulate their code caches without invalidating old branch targets, those stale targets can be reused for speculative control-flow hijacking, allowing attackers to leak sensitive data across security boundaries. BTR affects JIT engines in web browsers, language runtimes, and even operating system kernels, meaning a broad range of software is potentially vulnerable to data leakage. The attack also undermines existing Spectre-v2 mitigations such as Training Solo \(CVE-2024-28956 and CVE-2025-24495\), demonstrating that current defenses against branch target injection are insufficient against JIT-based variants. The attack is limited in scope to environments that use JIT compilation, which narrows but does not eliminate the practical risk surface. It turns JIT&\#x27;s code-cache reuse behavior into a speculative control-flow hijack primitive, and its ability to bypass existing mitigations like eIBRS highlights the ongoing challenge of defending against the broader Spectre attack family.

rss · Lobsters \(技术社区\) · Sep 30, 18:06

**Background**: Spectre-v2 \(also known as Branch Target Injection, or BTI\) is a class of speculative execution side-channel attacks disclosed in 2018 that exploit indirect branch prediction in modern CPUs to leak data across security boundaries. JIT \(Just-In-Time\) compilation is a performance technique used by JavaScript engines in browsers, language runtimes like Java and JavaScript, and some OS kernels to compile code at runtime for faster execution. Existing Spectre-v2 mitigations include hardware features like Intel&\#x27;s eIBRS and software measures like retpolines and Training Solo, all of which aim to prevent attackers from poisoning branch prediction structures.

## [Cisco SD-WAN Manager Zero-Day CVE-2026-76504 Allows Unauthenticated Admin Access](https://dev.to/etairos/cisco-sd-wan-manager-zero-day-cve-2026-76504-grants-unauthenticated-admin-api-access-2i0o) ⭐️ 8.0/10

Cisco disclosed on September 30 that CVE-2026-76504, a URI-encoding authentication bypass in Catalyst SD-WAN Manager&\#x27;s login session handling, is being actively exploited. The flaw lets unauthenticated remote attackers impersonate the default admin user \(netadmin role\) and gain full administrative control over the Manager and every edge device in the SD-WAN fabric it manages. This is the fourth critical SD-WAN Manager flaw Cisco has patched since May, and it carries a maximum CVSS score of 9.8 with active exploitation confirmed. Because the SD-WAN Manager sits at the apex of the fabric and pushes configuration and policy to every edge router, admin-level API access effectively hands an attacker control over an organization&\#x27;s entire wide-area network—no prior compromise or user interaction required. The bug scores 9.8 on CVSS, affects all on-prem SD-WAN Manager configurations, and Cisco provides no workaround—only fixed releases: 20.9.10.1, 20.12.8.2, 20.15.6.1, 20.18.4.1, 26.1.2.1, and 26.2.1. Notably, the advisory omits the 20.10, 20.11, 20.13, 20.14, and 20.16 release trains as well as Cloud-Pro and FedRAMP deployment types, so organizations on those branches should not assume they are unaffected.

rss · Dev.to · Sep 30, 20:04

**Background**: Cisco Catalyst SD-WAN Manager \(formerly called vManage\) is the centralized controller component of Cisco&\#x27;s software-defined wide-area networking solution; it handles configuration, policy, and troubleshooting for all edge routers in an SD-WAN fabric. Because it communicates directly with every device in the deployment and holds administrative credentials, it represents the highest-value target in an SD-WAN environment—compromising it gives an attacker effective administrative reach across the entire WAN. An authentication bypass vulnerability is a class of flaw in which improperly handled input \(here, URI encoding in HTTP requests\) lets an attacker evade the mechanism meant to verify a user&\#x27;s identity, gaining access without any credentials, session token, or user interaction.

## [Oncolytic Virus VCN-01 Plus Chemotherapy Improves Survival in Pancreatic Cancer](https://www.nature.com/articles/s41591-026-04705-y) ⭐️ 8.0/10

The randomized phase 2b VIRAGE trial showed that intravenous zabilugene almadenorepvec \(VCN-01\), a hyaluronidase-expressing oncolytic adenovirus, combined with gemcitabine and nab-paclitaxel \(GnP\), led to prolonged overall survival compared to GnP alone in patients with treatment-naive metastatic pancreatic cancer. Results were published in Nature Medicine on September 30, 2026. Metastatic pancreatic cancer is one of the deadliest malignancies with limited treatment options, making any survival improvement clinically meaningful. Demonstrating efficacy via intravenous delivery of an oncolytic virus broadens the applicability of virotherapy beyond injectable lesions and supports hyaluronidase-armed viruses as a viable strategy to overcome the dense stromal barrier in pancreatic tumors. VCN-01 is developed by Theriva Biologics \(formerly VCN Biosciences\) and encodes a human sperm hyaluronidase \(PH20\) designed to degrade hyaluronic acid in the tumor stroma, thereby enhancing viral intratumoral spread and improving chemotherapy penetration. The VIRAGE trial is randomized and evaluates systemic rather than intratumoral delivery, a notable distinction for oncolytic virotherapy in solid tumors.

rss · Nature Medicine · Sep 30, 00:00

**Background**: Oncolytic viruses are engineered or naturally occurring viruses that selectively infect and kill cancer cells while sparing normal tissue, while also stimulating anti-tumor immune responses. Adenoviruses are a common platform because they can be genetically modified to enhance tumor selectivity. Pancreatic adenocarcinoma is characterized by a dense desmoplastic stroma rich in hyaluronic acid, which creates high interstitial pressure that impedes drug delivery and contributes to its notorious treatment resistance. By expressing hyaluronidase, VCN-01 enzymatically breaks down this stromal barrier, potentially enabling both better viral dissemination within the tumor and improved access for co-administered chemotherapy.
