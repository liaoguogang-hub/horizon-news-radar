## [Asahi Linux 宣布苹果 M3 芯片适配取得进展](https://asahilinux.org/2026/09/m2-episode-1/) ⭐️ 8.0/10

Asahi Linux 项目宣布在为苹果 M3 代芯片移植 Linux 方面取得了重要进展，并发布了题为「M2: Episode 1 \(or, Asahi Linux on M3\)」的博客文章，详细介绍了最新的逆向工程成果。 这一里程碑将基于 Apple Silicon 的 Linux 支持从最初的 M1/M2 代扩展到了更新的机型，让希望在新款 ARM Mac 上运行自由开源操作系统的用户受益。同时也证明了以极快速度完整逆向工程苹果未公开的自研 SoC 是可行的。 Asahi Linux 完全依赖通过实时 MMIO 跟踪以及基于 Python 的原型虚拟机管理程序进行逆向工程，因为苹果不为其芯片提供任何公开文档。值得注意的是，HDMI 视频输出以及稳定的睡眠/唤醒功能仍未完善，这限制了日常使用的体验。

rss · Lobsters \(技术社区\) · 9月6日 00:52

**背景**: Asahi Linux 是由 Hector Martin 于 2020 年发起的社区项目，旨在将 Linux 内核及相关软件移植到搭载 Apple Silicon 的 Mac 上。Apple Silicon 是苹果为现代 Mac 和 iPad 设计的一系列基于 ARM 架构的系统级芯片（SoC），其中 M3 是 2023 年末发布的第三代产品。由于苹果不公开这些芯片的硬件规格，Asahi 团队必须对从 CPU 核心、GPU 到显示控制器和电源管理的每一个组件进行逆向工程，Linux 才能正常运行。

## [Trusting-Trust 攻击从编译器扩展至整个 Linux 发行版](https://arxiv.org/abs/2607.24888) ⭐️ 8.0/10

一篇研究论文证明，Ken Thompson 经典的 trusting-trust 编译器后门攻击可以在 GNU binutils 的 strip 工具中实现，而 strip 是一个构建后二进制处理工具，从而可以危及整个 Linux 发行版，而不仅仅是编译器的输出。 这一研究挑战了人们普遍认为 trusting-trust 攻击本质上是编译器问题的假设，将攻击面扩展到其他关键的构建工具，并对任何软件发行版的供应链安全提出了严峻质疑。 该攻击是在 GNU strip（一个从目标文件中移除符号信息的构建后工具）中实现的，而不是在编译器本身中。通过针对 strip 进行攻击，可以在整个发行版的构建过程中通过二进制篡改传播后门。

rss · Lobsters \(技术社区\) · 9月5日 10:58

**背景**: Ken Thompson 在 1983 年的图灵奖演讲《Reflections on Trusting Trust》中描述了一种理论上的攻击：被篡改的编译器在编译过程中植入后门，并且即使编译器从干净的源代码重新构建，后门也会自我复制。该攻击利用了用户通常信任编译器二进制文件但无法验证二进制文件是否与源代码匹配这一事实。GNU strip 工具是 binutils 中广泛使用的构建后工具，用于从目标文件中丢弃符号和调试信息，它是几乎每个 Linux 发行版构建过程中不可或缺的一部分。
