A major breach at IDScan has exposed up to 150 million driver&\#x27;s license and government ID records belonging to U.S. and Canadian citizens. The incident is being analyzed as a severe national security threat, with parallels drawn to the 2015 OPM breach that compromised sensitive federal employee data. Driver&\#x27;s license data is a core component of personally identifiable information \(PII\) and can be exploited for identity theft, fraud, and even to target individuals in national security roles. The scale of the breach, affecting the majority of American adults, raises urgent questions about data protection standards and corporate accountability for vendors handling sensitive identity documents. IDScan, a vendor that validates driver&\#x27;s licenses for businesses, has confirmed the breach but has not yet provided a public tool for individuals to check whether their data was compromised. Affected records include not just license numbers but also associated personal information, amplifying the risk of downstream fraud.

**Background**: Personally Identifiable Information \(PII\) refers to any data that can be used to identify a specific individual, and driver&\#x27;s license data is among the most sensitive forms of PII because it is often required for high-trust transactions. The 2015 OPM breach, attributed to Chinese state-sponsored hackers, exposed security clearance applications—including fingerprints—of over 20 million federal employees and applicants, and was widely regarded as a catastrophic intelligence loss. IDScan serves as a third-party identity verification vendor, meaning many businesses that rely on it have effectively centralized millions of citizens&\#x27; sensitive identity documents into a single point of failure.

## [Baseten GitHub Org Taken Over via Harbor Registry PAT in 25 Minutes](https://www.strix.ai/blog/baseten-harbor-github-pat-takeover) ⭐️ 8.0/10

Security researchers at Strix gained full admin access to Baseten&\#x27;s production GitHub organization in just 25 minutes by exploiting a misconfigured Harbor container registry to extract valid GitHub Personal Access Tokens \(PATs\). The exploit chain moved from an internet-exposed Harbor instance to complete GitHub org takeover, demonstrating a critical supply chain vulnerability. This case shows how a single misconfigured container registry can lead to total compromise of an organization&\#x27;s source code, CI/CD pipelines, and potentially every customer who depends on that code. Any startup or enterprise using Harbor registries with hardcoded or leakable credentials is at similar risk of supply chain attacks. The attack leveraged Harbor&\#x27;s image labels or build metadata to discover embedded GitHub PATs with admin scopes, illustrating how CI/CD build contexts frequently leak secrets into container images. Recent disclosures like CVE-2026-4404 \(CVSS 9.4\) have shown that default credentials and policy misconfigurations in Harbor remain a widespread industry-wide problem.

rss · Hacker News \(热门\) · Sep 15, 18:11

**Background**: Harbor is an open-source, enterprise-grade container image registry commonly used to store and distribute Docker images in cloud-native environments. It integrates with CI/CD pipelines and often contains credentials needed to pull or push images. GitHub Personal Access Tokens \(PATs\) are authentication credentials that grant access to GitHub repositories and organizations; if a PAT with admin permissions leaks, an attacker can take full control of the associated GitHub organization, including the ability to modify source code, steal secrets, and compromise all dependent software builds.

## [Wayback Machine Rate Limiting Due to AI Scrapers](https://blog.archive.org/2026/09/15/an-update-on-wayback-machine-access/) ⭐️ 7.0/10

The Internet Archive explained that aggressive rate limiting on the Wayback Machine has been implemented to combat waves of high-volume automated traffic from AI scrapers that bypass site restrictions by crawling archived copies of web pages instead. The Archive is working on improving bot detection to better distinguish abusive traffic from legitimate users, and has invited false positives to be reported via email. This situation highlights the growing tension between AI companies&\#x27; insatiable demand for training data and the preservation of public web infrastructure. The Wayback Machine is a critical non-profit resource for researchers, journalists, and the public, and over-aggressive rate limiting risks alienating legitimate users while AI scrapers continue to extract value without compensation. Users report receiving HTTP 429 \(Too Many Requests\) errors even during normal browsing activity such as navigating the calendar interface, and some corporate or airport networks are effectively blocked entirely. The Archive notes that some site owners have already opted out of having their content crawled via the Wayback Machine due to this abuse, further reducing the utility of the service.

hackernews · Hacker News \(热门\) · Sep 15, 17:52 · [Discussion](https://news.ycombinator.com/item?id=49716176)

**Background**: The Internet Archive is a non-profit digital library founded in 1996 by Brewster Kahle, best known for the Wayback Machine, which preserves snapshots of web pages over time. Its default search API rate limit has recently been reduced to around 24 requests per minute. AI scrapers have increasingly been found circumventing robots.txt directives—the standard mechanism publishers use to block automated crawlers—to harvest content for training large language models, sometimes routing through web archives to bypass site-level blocks.
