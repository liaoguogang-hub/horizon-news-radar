## [WordPress Patches Critical Unauthenticated Path Traversal RCE Vulnerability](https://github.com/WordPress/wordpress-develop/security/advisories/GHSA-7hp8-65ch-5whp) ⭐️ 8.0/10

WordPress version 7.1.2 was released to fix a critical unauthenticated path traversal vulnerability that can lead to conditional remote code execution, with the patch backported across all supported branches back to version 4.7. Because WordPress powers a huge portion of the web and this flaw requires no authentication, a large number of sites were potentially exposed to attackers who could read sensitive files or—under certain conditions—execute arbitrary code on the server. The vulnerability is classified as a path traversal \(also called directory traversal or &\#x27;dot-dot-slash&\#x27;\) flaw that lets unauthenticated attackers access files outside the intended directory. Achieving full RCE requires additional conditions to be met, which is why it is labeled &\#x27;conditional RCE.&\#x27; Roughly one-third of WordPress installations are believed to not be running the latest branch.

hackernews · Hacker News \(热门\) · Sep 22, 16:33 · [Discussion](https://news.ycombinator.com/item?id=49803959)

**Background**: A path traversal vulnerability occurs when an application uses user-supplied input to construct file paths without proper validation, allowing attackers to use sequences like &\#x27;../&\#x27; to escape the intended directory and read or include arbitrary files on the server. When such a flaw is combined with other weaknesses—such as local file inclusion of executable PHP files—it can escalate from arbitrary file read to remote code execution. WordPress, being the most widely deployed content management system, is a frequent target; unpatched WP installations are commonly scanned and exploited by automated bots shortly after vulnerabilities are disclosed.

## [NHS-Galleri Trial: Multi-Cancer Blood Test Performance Evaluated](https://www.nature.com/articles/s41591-026-04652-8) ⭐️ 8.0/10

Secondary endpoint analyses from the NHS-Galleri randomized controlled trial, published in Nature Medicine on September 22, 2026, evaluate the performance of a blood-based multi-cancer early detection \(MCED\) test when added to usual care in over 142,000 participants without suspected cancer. This is one of the largest RCTs ever conducted for a multi-cancer early detection screening test, and its findings could shape whether blood-based MCED tests are adopted in national screening programs. The results will influence clinical guidelines, health policy, and the broader integration of liquid biopsy technologies into preventive medicine. The trial uses GRAIL&\#x27;s Galleri test, which detects cell-free DNA \(cfDNA\) methylation patterns in the bloodstream to identify cancer signals and predict the tissue of origin. The published analyses focus on secondary endpoints rather than primary outcomes, which are typically assessed post-hoc and may not have been powered for definitive conclusions during trial design.

rss · Nature Medicine · Sep 22, 00:00

**Background**: Multi-cancer early detection \(MCED\) tests aim to screen for multiple cancer types from a single blood sample by detecting tumor-derived signals such as DNA fragments shed by cancer cells, a technique known as liquid biopsy. Unlike traditional single-cancer screening methods \(e.g., mammography or colonoscopy\), MCED tests like Galleri target many cancers simultaneously, including those lacking established screening protocols. A randomized controlled trial \(RCT\) is considered the gold standard for evaluating whether adding such a test to usual care meaningfully improves outcomes, while secondary endpoints provide supplementary measures beyond the primary outcome and are often analyzed to explore additional clinical questions.
