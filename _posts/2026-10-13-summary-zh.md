## [在 Python 中实现每秒数十 GB 的 JSON 解析](https://lemire.me/blog/2026/10/12/parsing-json-at-tens-of-gigabytes-per-second-in-python/) ⭐️ 8.0/10

Daniel Lemire 发表了一篇博文，展示了如何在 Python 中通过优化技术（很可能是基于 simdjson 等 SIMD 加速的原生库）实现每秒数十 GB 的 JSON 解析速度。 JSON 解析是数据管道、机器学习预处理和 Web 服务中的常见瓶颈。在传统上被视为慢语言的 Python 中实现如此极高的吞吐量，大大缩小了与 C/C++ 之间的性能差距，有望改变 Python 生态中高吞吐量数据工程任务的处理方式。 该方法几乎可以确定是通过 cysimdjson 等库将 Python 与经过 SIMD 优化的原生 C/C++ 代码桥接起来，而非纯 Python 解析。速度提升主要体现在原始反序列化阶段；将结果进一步转换为 Python 对象（dataclasses、dict、Pydantic 模型）通常会带来每条记录数微秒级的额外开销。

rss · Lobsters \(技术社区\) · 10月12日 15:24

**背景**: JSON（JavaScript Object Notation）是 Web API、配置文件和数据管道的事实标准数据交换格式。SIMD（单指令多数据）是一种 CPU 特性，允许一条指令同时对多个数据点执行操作，从而极大地加速结构化文本的解析速度。simdjson 由 Daniel Lemire 本人创建，是一个著名的 C++ 库，利用 SIMD 指令以每秒数十亿字节的速度解析 JSON，而 pysimdjson、cysimdjson 等 Python 绑定库已经将这一性能暴露给 Python 用户。标准库中的 json 模块则要慢得多，因为它是纯 Python C 代码实现，没有使用 SIMD 优化。

## [基于逾 5.2 万患者构建的肿瘤恶病质多模态图谱](https://www.nature.com/articles/s41591-026-04689-9) ⭐️ 8.0/10

## [最后一次月经标志多系统生理骤变](https://www.nature.com/articles/s41591-026-04614-0) ⭐️ 8.0/10

发表在《自然·医学》上的一项大规模人群研究发现，最后一次月经是一次骤变性的多系统生理转折点，而非渐进式的衰退过程。研究人员利用一种新颖的计算框架分析了两个独立队列的横断面实验室数据，发现性激素变化在绝经发生前十余年就已启动。 这一发现挑战了将更年期视为渐进性激素过渡的主流观点，识别出一个可作为临床干预精准生物标志物的明显生理转折点。它对女性健康研究具有深远意义，有望改变激素替代疗法的时机、心血管风险评估以及骨骼健康监测的方式。 该研究采用一种新颖的计算框架，应用于两个独立队列的横断面实验室数据，从而实现了对生理变化时间和性质的群体规模推断。核心发现是：尽管性激素变化在绝经前十余年就已开始，但最后一次月经本身构成了一个离散的临界点，多个生理系统在该节点发生骤变。

rss · Nature Medicine · 10月12日 00:00

**背景**: Menopause is officially defined as 12 consecutive months without menstruation, typically occurring between ages 45 and 55, with an average age of 51 in the United States. The menopausal transition is generally understood as a gradual process driven by declining ovarian function, during which progressively anovulatory cycles occur until menstruation ceases entirely. Sex hormones such as estradiol fluctuate during this transition, while gonadotropins \(FSH and LH\) rise to maintain normal circulating estrogen levels until late in the transition.

## [ai-critic：跨七个维度审计机器学习模型](https://dev.to/luizsdemarco/your-94-accuracy-model-might-still-be-a-bad-model-auditing-ml-across-7-dimensions-47pc) ⭐️ 6.0/10

开发者 Luiz Seabra DeMarco 发布了一个开源 Python 库 ai-critic，可以从七个维度审计机器学习模型：性能、鲁棒性、可解释性、校准、数据质量、公平性和复杂度。该库采用任务感知设计，用户声明任务类型（如分类、异常检测、聚类），库会自动选择相应的评估策略。 仅依赖准确率等单一指标可能掩盖模型的严重缺陷，如过度自信、对噪声敏感或对特定子群体的偏见，这些问题往往要到生产环境才会暴露。标准化的多维度审计有助于团队在上线前发现这些问题，也契合日益受到关注的 MLOps 和负责任 AI 实践。 如果某个维度无法被衡量（例如未声明敏感属性用于公平性评估，或没有概率输出用于校准），报告会将该维度标记为 &\#x27;inconclusive&\#x27; 或 &\#x27;not\_applicable&\#x27;，并从总分中排除该维度，而不是给出虚高的默认值。报告还会记录评估协议、权重和分数转换过程，使聚合结果可审计、可追溯。

rss · Dev.to · 10月13日 00:43

**背景**: 模型校准（calibration）衡量的是模型预测概率与实际结果的一致程度；一个模型可能准确率很高，但校准很差（过度自信或信心不足）。鲁棒性（robustness）衡量的是模型在输入扰动（如噪声或对抗攻击）下预测的稳定性。公平性指标（如人口统计均等 demographic parity 和均等化几率 equalized odds）用于量化模型的预测是否在由敏感属性（如性别、种族）定义的子群体之间存在系统性差异。将这些维度结合起来，能比单纯看准确率更全面地评估模型质量。
