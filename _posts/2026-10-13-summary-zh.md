## [Ledger 确认硬件钱包中存在间谍芯片植入](https://www.bleepingcomputer.com/news/security/ledger-confirms-hardware-wallet-spy-implant-behind-crypto-thefts/) ⭐️ 8.0/10

Ledger 确认，包含隐蔽 eSIM 模块和一颗小型 CPU 的受损硬件钱包在零售渠道被出售，导致约 9200 万美元的加密货币被盗。该植入物是一块连接在安全芯片与 OLED 显示屏之间 SPI 总线上的小型电路板，用于读取屏幕像素、识别助记词，并通过 LTE 将其传输出。 此次事件验证了此前被认为不切实际的对硬件钱包的攻击向量，表明物理供应链攻击并非多虑，而是切实存在的持续威胁。它对整个自托管生态产生了深远影响，削弱了人们对市售硬件钱包的信任，并促使业界紧急呼吁加强防篡改机制和供应链验证。 该攻击通过被动拦截显示信号并使用 OCR，完全绕过了 CC EAL5+ 认证的安全芯片，无需破解密码学保护。受感染设备明显在德国各地的 MediaMarkt 实体店货架上销售，追溯源头涉及一家与 CryptoBilis 相关的东南亚经销商链条。

hackernews · Hacker News \(热门\) · 10月12日 10:09 · [社区讨论](https://news.ycombinator.com/item?id=50054092)

**背景**: 像 Ledger Nano X 这样的硬件钱包是专为离线安全存储加密货币私钥而设计的物理设备。它们依赖一颗“安全芯片”（与护照所采用的标准相同）来确保私钥永不离开设备。助记词（私钥的人类可读形式）会在设备屏幕上显示以供备份。安全芯片被广泛认为具有防篡改能力，但设备的屏幕输出是用户使用所必需的环节。此次攻击专门针对安全芯片与屏幕之间的连接，利用了此前被认为仅存在于理论中的物理安全漏洞。

## [后量子加密「正确答案」指南更新](https://words.filippo.io/right-answers/) ⭐️ 8.0/10

Filippo Valsorda 发布了更新版的「Cryptographic Right Answers」指南，专门针对后量子密码学，推荐了面向量子安全时代的最佳实践和算法选择。这篇文章延续了 Colin Percival 于 2009 年开创、Thomas Ptacek 和 Latacora 相继接力的传统，现针对后量子过渡进行了更新。 该指南被做出实际密码学决策的安全工程师广泛参考，其后量子版本的发布恰逢组织必须开始从易受量子攻击的经典算法过渡的关键时刻。这些推荐直接影响整个行业的库默认配置、TLS 配置以及应用层安全选择。 该指南强调，后量子算法「目前被认为（但尚未被证明）能够抵御量子计算机的密码分析攻击」，反映了该领域持续存在的不确定性。它还建议不要自行实现公钥加密或直接使用底层加密库，而是推荐使用经过验证的更高级抽象。

## [Python 3.15 正式发布：引入惰性导入，Python 3.10 停止维护](https://simonwillison.net/2026/Oct/12/python-3-15/) ⭐️ 8.0/10

Python 3.15 正式发布，通过 PEP 810 引入了显式惰性导入（使用新的 \`lazy\` 关键字），并通过 PEP 798 引入了推导式中的解包语法。与此同时，Python 3.10 已停止维护，库维护者可以放弃对 3.10 的支持并开始采用 Python 3.11+ 的特性。 PEP 810 的显式惰性导入直接解决了 Python 长期存在的启动时间问题——这对 CLI 工具和具有大量可选依赖的应用程序来说尤其痛苦。Python 3.10 的退役将释放一波库的现代化升级，这些库一直在等待使用 3.11+ 的特性，如 \`Self\`、\`tomllib\` 和改进的错误信息。 \`lazy\` 关键字将模块加载延迟到首次访问符号时才执行，保留了现有的模块级副作用语义——这与让所有导入都变成惰性不同，因为后者会破坏插件注册模式。本次发布由 Hugo van Kemenade（3.14 和 3.15 的发布经理）策划；Ruff 等生态工具已提供 \`lazy-import-mismatch\`（TID254）检查规则，用于强制执行惰性导入策略。

rss · Simon Willison \(AI 跨行业洞察\) · 10月12日 18:15

**背景**: Python 遵循年度发布周期，每个版本获得约五年的维护期；当某个版本到达生命周期终点后，将不再获得安全补丁。惰性导入（将模块加载延迟到符号实际使用时才执行）长期以来可通过手动方式实现（例如将导入包裹在函数内部），但 PEP 810 将其提升为一等语言特性，提供了显式语法。Simon Willison 的文章值得注意的地方在于，他将新语法与他自己的 LLM CLI 工具中的实际问题联系起来——该工具的插件引入 \`sentence\_transformers\` 会让启动时间增加数秒。
