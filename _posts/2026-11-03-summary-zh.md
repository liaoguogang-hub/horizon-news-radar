## [PROGRESS 试验评估中度主动脉瓣狭窄的 TAVR 疗效](https://www.nejm.org/doi/full/10.1056/NEJMoa2607326?ai=nejm&amp;af=R&amp;rss=currentIssue) ⭐️ 9.0/10

这项多中心随机 PROGRESS 试验比较了 TAVR 与谨慎临床监测在 65 岁及以上、患有中度主动脉瓣狭窄且至少存在一项进展风险因素患者中的疗效。该研究已在《新英格兰医学杂志》提前在线发表，旨在确定提前进行瓣膜置换能否比观察等待更好地防止病情恶化。 该试验纳入患有中度主动脉瓣狭窄并伴有相关风险特征的患者，公开资料显示这些风险标记包括可归因于主动脉瓣狭窄的症状，以及左心室射血分数不高于 50%。对照组接受临床监测，而非常规立即进行瓣膜置换；现有摘要未提供完整的数值结果、安全性数据或随访结果。

rss · NEJM · 最新文章 · 11月2日 05:40

**背景**: 主动脉瓣狭窄是主动脉瓣进行性缩窄，可影响血液从左心室流向主动脉。TAVR 是一种微创导管介入手术，通过导管将病变主动脉瓣替换为人工瓣膜。中度主动脉瓣狭窄通常采用定期临床随访和超声心动图监测，而 TAVR 已是治疗重度主动脉瓣狭窄的成熟方法。

## [本地运行的 Qwen 3.8 27B 展现权重空间解读能力](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/) ⭐️ 8.0/10

西蒙·威利森在笔记本电脑上使用 Qwen 3.8 27B 复现了权重解读实验，将此前由前沿模型 GPT-6 Astra 展现的能力扩展到本地模型。该模型在没有代码执行或其他工具的情况下接收神经网络原始浮点权重，并似乎能够推断网络所学习的功能。 这项演示表明，一些权重空间推理能力可能并非高价前沿模型所独有，本地模型也具备相关表现。如果结果可靠，开发人员便可能通过直接检查和修改权重来改进模型，而无需编写传统训练循环，但目前的非正式演示尚不足以证明其稳健性。 原始实验训练了四个策略网络，让它们分别学习简化版 10×10 网格上的 Breakout、Pong、Pac-Man 和 Freeway，然后要求大语言模型在无工具且仅生成一次回答的条件下，直接依据权重判断游戏。配套论文还报告了更具挑战性的权重编辑结果，包括修改 Qwen3.5-0.8B 的 0.016% 权重后，MATH-500 成绩从 7.9% 提升至 48.1%；但评论者认为，工具辅助更新和类似人工研究步骤应与原生的无代码权重操作严格区分。

rss · Simon Willison \(AI 跨行业洞察\) · 11月3日 16:29 · [社区讨论](https://news.ycombinator.com/item?id=50355251)

**背景**: 权重空间编程是指利用语言模型的推理能力检查或修改神经网络的原始参数，而不是只通过提示词、代码或常规优化来改变模型行为。模型权重通常通过学到的数值变换影响输出，因此在不执行网络的情况下识别或编辑权重，是一项不同于普通工具使用的能力。该研究延续了此前关于 GPT-6 Astra 能够读取权重、推断网络行为并直接编写小型游戏策略网络的报告。

## [Postman 被指静默安装 AI 插件并传输 API 数据](https://github.com/postmanlabs/postman-app-support/issues/14370) ⭐️ 8.0/10

一个 GitHub 支持工单指控，Postman Desktop 会静默自动安装 Codex 和 Claude Code 插件、信任自身钩子，并尝试把详细的 API 请求数据发送到 Postman 服务器。据称，当用户通过 Postman 变量填充请求参数时，展开后的秘密值也可能被包含在内，而阻止该日志端点可能导致应用无法正常运行。 如果指控属实，这一行为会给广泛使用的 API 开发平台带来隐私、秘密管理、合规和企业治理风险。问题对医疗保健及其他受监管团队尤其严重，因为 API 请求中可能包含凭据、令牌、个人数据或机密商业信息。 据报，相关遥测会包含请求模板中替换后的展开值，例如 \`\{\{some\_secret\}\}\`，而不只是字面占位符。Postman 文档将 Postman Vault 描述为一种可在运行时访问敏感值、且无需在集合或请求中暴露其值的方法，但该工单讨论的是通过请求日志进行传输；现有证据来自用户报告和支持讨论，并非完整的独立审计。

hackernews · Hacker News \(热门\) · 11月3日 17:22 · [社区讨论](https://news.ycombinator.com/item?id=50354960)

**背景**: Postman 是一款用于构建、测试和监控 API 请求的图形化平台，其变量功能可以复用主机、令牌和查询参数等值。AI 编码代理集成能够通过模型或代理辅助流程扩展开发工具，但自动安装这类插件会引发有关用户同意、信任边界以及谁有权批准可执行钩子的独立问题。Postman Vault 的设计目标是让敏感值不出现在已保存的请求定义中，但开发者仍应核实每项请求、脚本、日志功能和插件实际传输的数据。

## [将 Mac 基础设施扩展到数据中心规模](https://namespace.so/blog/mac-at-any-scale) ⭐️ 8.0/10

这篇文章分析了在数据中心运营 Apple 硬件和 macOS 时面临的工程难题，包括自动化、虚拟化、代码签名和部署。作者认为，生态系统在服务器场景中的不足往往会迫使团队采用成本高昂的变通方案，而不能直接依靠专用的 Mac 服务器平台。 Apple Silicon 正被越来越多地用于持续集成运行器和其他 macOS 工作负载，因此可靠的远程运维对开发基础设施愈发重要。这项分析揭示了面向桌面的默认设计如何提高数据中心规模下的运维复杂度和成本。 主要障碍包括 macOS 虚拟化限制、分散的自动化与签名流程，以及让无人值守机器保持完全可用的困难。据报道，Mac mini 启动后可能仍需手动解锁，而 VirtualBuddy 和 macOS-vz-kubelet 等项目则展示了基于 Apple 虚拟化框架和 Kubernetes 的变通方案。

hackernews · Hacker News \(热门\) · 11月3日 14:53 · [社区讨论](https://news.ycombinator.com/item?id=50352758)

**背景**: macOS 传统上面向交互式个人设备而非无人值守的服务器集群，因此启动解锁等功能可能打断远程自动化。受支持的 Apple Silicon 主机可以通过虚拟化工具运行 macOS 虚拟机，而 macOS-vz-kubelet 则将这种方式扩展到 Kubernetes 上的原生 macOS 工作负载。这些工具体现了将桌面操作系统和开发生态改造成适配云端及数据中心环境的努力。
