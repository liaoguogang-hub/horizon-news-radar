## [Moderna-Merck mRNA Cancer Vaccine Succeeds in Phase 3 Melanoma Trial](https://arstechnica.com/health/2026/08/mrna-cancer-vaccine-succeeded-in-phase-3-melanoma-trial-moderna-and-merck-say/) ⭐️ 9.0/10

Moderna and Merck announced that their personalized mRNA cancer vaccine, intismeran autogene, in combination with Merck&\#x27;s Keytruda \(pembrolizumab\), met both primary and key secondary endpoints in the Phase 3 INTerpath-001 trial for patients with completely resected Stage IIB-IV cutaneous melanoma, demonstrating statistically significant improvements in recurrence-free survival \(RFS\) and distant metastasis-free survival \(DMFS\). This represents the first Phase 3 success for a personalized mRNA-based cancer therapy, potentially establishing a new adjuvant treatment paradigm for resected melanoma and validating the broader mRNA cancer vaccine platform developed during the COVID-19 era. The trial enrolled patients with completely resected Stage IIB, IIC, III, or IV cutaneous melanoma who had not received prior systemic therapy. While the interim analysis showed significant RFS and DMFS benefits over Keytruda alone, overall survival \(OS\) data is still pending, and full Phase 3 data has not yet been publicly presented or peer-reviewed.

**Background**: Melanoma is an aggressive form of skin cancer with high rates of recurrence after surgical resection, particularly in advanced stages. mRNA cancer vaccines work by instructing the patient&\#x27;s own cells to produce tumor-specific neoantigens—unique proteins found on cancer cells—training the immune system to recognize and attack residual cancer cells. Keytruda is an immune checkpoint inhibitor that works by blocking the PD-1 pathway, helping the immune system detect tumors, and combining immunotherapy with a cancer vaccine aims to amplify this immune response. Phase 3 trials are large-scale, late-stage studies required for regulatory approval.

## [CSS Weaponized as Email-Based Attack Vector](https://portswigger.net/research/css-the-bomb-inside-your-inbox) ⭐️ 8.0/10

PortSwigger researcher Gareth Heyes revealed that sanitized CSS inside email messages can be weaponized to escape message boundaries and attack webmail interfaces across providers including Outlook, Gmail, Fastmail, Proton Mail, Yahoo Mail, and AOL Mail. The research, presented at Black Hat, demonstrates chains that can capture passwords, tokens, and other sensitive data, and even enable indirect prompt injection from email into AI browsers like OpenAI&\#x27;s Atlas. This research exposes a largely underexplored attack surface: email clients have historically been treated as safer than arbitrary web pages, yet they parse rich HTML and CSS. It affects hundreds of millions of users across major webmail providers and introduces new risks for AI-powered browsers that consume email content, potentially reshaping how email clients sanitize content and how AI systems handle untrusted input. The attacks rely on CSS attribute selectors and sanitization bypasses to leak data character-by-character through styling side channels, a technique documented in earlier web-based CSS exfiltration research. The GitHub repository accompanying the talk provides proof-of-concept code and test cases for defensive research, and the work also demonstrated indirect prompt injection against OpenAI&\#x27;s Atlas browser via Fastmail.

rss · Lobsters \(技术社区\) · Aug 18, 13:30

**Background**: CSS \(Cascading Style Sheets\) is the language used to style HTML documents, and its attribute selectors can apply different styles based on element attribute values. Security researchers have long known that injected CSS on a webpage can be abused to exfiltrate data by making requests to attacker-controlled servers based on attribute values, such as prefix-matching URL characters. Email clients, especially webmail, render HTML and CSS much like browsers, but sanitizers are typically designed to block scripts rather than creative CSS abuse. OpenAI Atlas is a recent AI-powered browser that can process web and email content, opening a new frontier where untrusted CSS in an email could influence AI behavior.

rss · Lobsters \(技术社区\) · Aug 19, 09:34

**Background**: On Linux, programs can be either statically linked \(all dependencies bundled into the executable\) or dynamically linked \(relying on shared libraries, or .so files, loaded at runtime by the dynamic linker such as ld-linux.so\). Static linking produces portable, self-contained binaries but prevents the program from using host-provided shared libraries at runtime. This is problematic when, for example, a musl-linked binary needs to load glibc-built GPU drivers, since the two C libraries are not ABI-compatible. Tools like Solo bridge this gap by implementing a custom loader that can resolve and load .so files even from a statically linked binary.
