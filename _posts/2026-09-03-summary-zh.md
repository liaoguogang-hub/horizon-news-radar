## [实现 FMA 操作时发现 C 和 Rust 标准库的缺陷](https://shnatsel.github.io/implementing-fma-finding-bugs-in-std/) ⭐️ 8.0/10

一篇开发者博文详细介绍了实现 FMA（融合乘加）操作的过程，并在此过程中发现了 C 和 Rust 标准库中的一些细微缺陷。 这一发现具有重要意义，因为 C 和 Rust 的标准库支撑着庞大的系统软件和数值计算生态系统，任何细微的数值缺陷都可能在依赖 IEEE 754 浮点语义的无数应用中悄无声息地传播。 作者采用基于属性的测试（property-based testing）方法系统性地生成输入，以暴露 FMA 实现中的边界情况，展示了一种比手工单元测试更严格的方法论。对 C 和 Rust 库的跨语言对比表明，两大生态系统中都存在真实的、可被利用的缺陷。

rss · Lobsters \(技术社区\) · 9月2日 16:19

**背景**: 融合乘加（FMA）是一种浮点运算，它通过单次舍入完成 a\*b + c 的计算，比分开执行乘法和加法能获得更精确的结果。现代 CPU（包括 Intel 和 AMD）都为标量和 SIMD 场景提供了专门的 FMA3 指令（AMD 还提供 FMA4）。基于属性的测试是一种方法论，其中测试框架自动生成大量随机或边界输入，以验证实现是否满足某个已定义的数学或行为属性，而不是仅仅检查手工挑选的示例值。

## [Claude AI 为 Paint.NET Linux 版编写 18 万行逆向工程 Direct2D 代码](https://simonwillison.net/2026/Sep/2/rick-brewster/) ⭐️ 8.0/10

Paint.NET 的创始人 Rick Brewster 透露，Claude AI 被用于编写一个包含 18 万行代码的、从零开始逆向工程实现的微软 Direct2D 图形 API，封装为 PaintDotNet.Windows.Direct2D1.Managed.dll，从而让 Paint.NET 能够通过 WINE 在 Linux 上运行。Brewster 将大部分代码描述为「氛围编程」（vibe coded），即未经严格审查，基本是一种「你信我就行」的开发方式。 这是目前公开记录中规模最大的、由 AI 为真实软件产品生成特定领域系统级代码的案例之一，表明大语言模型能够承担逆向工程复杂专有 API 这类任务，其规模远超人类开发者单独完成的能力。Brewster 直率地承认自己无法审查这 18 万行 AI 生成的代码，这引发了关于 AI 辅助软件工程中信任、维护负担和质量保证的重要问题。 Brewster 指出，Claude 需要大量人工监督，尤其是在 COM 资源管理方面（它最初忘记对引用计数对象调用 AddRef\(\)），并且偶尔会做出糟糕的架构决策。逆向工程的特效库（包括 Direct2D 内置特效所需的所有公式）被描述为「相当巧妙且不知疲倦」。仅这个 AI 生成的 Direct2D 模块就有约 18 万行代码，约为 Paint.NET 整个 70 万行代码库的四分之一，而后者是 Brewster 花了 20 多年亲自编写的。

rss · Simon Willison \(AI 跨行业洞察\) · 9月2日 05:50

**背景**: Direct2D 是微软推出的硬件加速即时模式 2D 图形 API，用于高性能渲染几何图形、位图和文本，它历来是在其他平台上运行 Windows 应用程序的最大兼容性障碍之一。WINE 是一个免费开源的兼容层，通过在运行时翻译 Windows API 调用（而非模拟），使 Windows 软件能够在 Linux 等类 Unix 系统上运行。「氛围编程」（vibe coding）一词由 Andrej Karpathy 于 2025 年 2 月提出，用来描述一种 AI 辅助编程工作流：开发者根据运行结果和迭代式提示来接受 AI 生成的代码，而不是逐行审查。

## [地下探测器记录到暗物质粒子的有力证据](https://www.wired.com/story/scientists-find-most-convincing-evidence-yet-dark-matter-particle/) ⭐️ 8.0/10

一个地下探测器记录到了一次异常相互作用，其特征与暗物质粒子相符，构成了迄今为止最具说服力的暗物质粒子证据。此次探测被描述为信号微弱但前景可观，属于初步发现，仍需进一步验证。 直接探测到暗物质粒子将解开现代物理学和宇宙学中最深奥的谜团之一，可能重塑我们对标准模型以及宇宙基本组成的理解。若得到证实，也将为粒子物理学、天体物理学和宇宙学开辟全新的研究方向。 该信号由一个地下探测器记录，这类探测器被部署在地表深处，以屏蔽宇宙射线和其他背景辐射的干扰。此次探测仍属于初步阶段，科学家将其视为有前景但尚不确定的证据，需要独立的复现实验加以验证。

rss · Wired · 9月3日 11:30

**背景**: 暗物质是一种不可见的物质形式，其质量约为普通物质的五倍，只能通过其对星系和宇宙大尺度结构的引力效应来探测。目前主流的理论候选粒子包括弱相互作用大质量粒子（WIMP）和轴子，这两者都源自标准模型之外的物理理论。由于暗物质与普通物质的相互作用极其微弱，探测器必须放置在地下深处，以过滤宇宙射线和其他地表辐射的噪声，从而捕捉这些粒子可能产生的罕见信号。

## [CircleCI 缓存键 Bug 静默提供过期依赖](https://dev.to/mukesh_13/the-circleci-cache-key-bug-thats-silently-serving-your-builds-stale-dependencies-4jpf) ⭐️ 6.0/10
