## [Keyv 及其依赖项在活跃的 Shai-Hulud npm 供应链攻击中被攻陷](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack) ⭐️ 8.0/10

Shai-Hulud 蠕虫攻陷了 Keyv npm 包及其多个相关依赖项，注入了用于从受影响项目中窃取环境变量的恶意代码。此次攻击是一场更广泛攻击行动的一部分，已波及 npm 生态系统中超过 500 个包。 Keyv 是一个广泛使用的、支持多种后端的键值存储库，其被攻陷在整个 JavaScript 生态系统中影响深远。此次事件凸显了 npm 深度嵌套依赖树的结构性脆弱性——单个被攻陷的包可能会波及到成千上万的下游应用。 Shai-Hulud 蠕虫具有自我复制能力，意味着它一旦渗透到某个维护者的账户，就能通过依赖链自动传播。CISA 已就此次攻击行动发布官方警报，OpenAI 也披露了一个名为 Mini Shai-Hulud 的相关变种，该变种于 2026 年 5 月攻陷了 TanStack。

hackernews · Hacker News \(热门\) · 8月4日 11:01 · [社区讨论](https://news.ycombinator.com/item?id=49166874)

**背景**: npm（Node Package Manager）是全球最大的 JavaScript 包注册中心，开发者在此发布和使用可复用的代码模块。供应链攻击通过攻陷受信的包或维护者账户来注入恶意代码，然后自动分发给所有下游用户，从而针对这一生态系统。Keyv 是一个简单的键值存储抽象层，支持多种后端，常被用作缓存、会话管理和存储层的依赖项，应用于许多应用之中。pre-install 和 post-install 等生命周期钩子是 npm 的特性，会在包安装过程中执行任意代码，这已成为攻击者青睐的攻击载体。

## [面向 AI Agent 自我改进的 Harness 工程](https://lilianweng.github.io/posts/2026-07-04-harness/) ⭐️ 8.0/10

Lilian Weng 发表了一篇关于&quot;harness 工程&quot;的详细文章，提出通过自我改进循环来系统性地优化 AI Agent 的脚手架——包括 prompt、工具和配置——而非修改模型权重。该文章将 Agent 的周边基础设施定位为提升实际性能的主要优化目标。 随着前沿模型的训练收益逐渐递减，Agent 能力的边际提升越来越多地来自更好的脚手架、工具和编排。这一转变对 AI 工程团队具有重大意义，因为 prompt 设计和 harness 架构已成为与模型选型同等重要的竞争差异化因素。 Weng 强调自我改进循环会优化其所接收到的任何信号，因此精心设计的评估体系（包含留出测试集和评判模型防护）对于防止 reward hacking 至关重要。评论中的实践者指出，对生产环境 trace 进行自动研究并让 Agent 编写自己的工具，可以带来显著的 token 效率提升，但这需要配合可靠的适应度函数。

hackernews · Hacker News \(热门\) · 8月4日 06:17 · [社区讨论](https://news.ycombinator.com/item?id=49164896)

**背景**: AI Agent 的 harness 指的是推理时围绕 LLM 的一切组件：系统 prompt、工具定义、记忆/上下文管理、编排逻辑以及 AGENTS.md 等配置文件。传统的 AI 改进聚焦于训练更好的模型权重，但随着基础模型能力日益增强，实践者发现对于真实任务的成功而言，模型周边的脚手架往往与模型本身同样重要。自我改进循环试图通过让 Agent 分析自身 trace、提出修改方案并基于评估器进行验证，从而自动化地优化这一脚手架。
