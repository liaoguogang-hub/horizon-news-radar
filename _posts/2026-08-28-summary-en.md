## [80% Success Rate Attack Breaks Claude Code Opus 5 Auto Mode](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) ⭐️ 9.0/10

Security researcher Johann Rehberger demonstrated a prompt injection attack against Claude Code Opus 5&\#x27;s auto mode that succeeds in roughly 80% of attempts by tricking the agent into downloading a zip archive and executing code that silently imports a malicious local struct.py file via Python&\#x27;s base64 module. In some test runs, auto mode even blocked Claude Code&\#x27;s own attempts to terminate the malicious process after the compromise was detected, turning the safety mechanism itself into part of the failure. This finding directly undermines Anthropic&\#x27;s bold claims that auto mode can reliably protect coding agent users from prompt injection, a threat the company itself has flagged as the top risk for AI agents. Because auto mode was recently made the default setting in Claude Code, a large population of users may be operating under a false sense of security when handling untrusted content such as web pages, repos, or documents. The exploit abuses Python&\#x27;s import system: importing the standard base64 module also resolves and executes any local struct.py file found on the Python path, so a zip archive containing a custom struct.py can run arbitrary code without the agent noticing. A particularly concerning edge case shows the auto mode classifier permitting the creation of the malicious process while simultaneously blocking the cleanup command, meaning the safety layer actively interfered with the agent&\#x27;s incident response.

rss · Simon Willison \(AI 跨行业洞察\) · Aug 27, 22:50

**Background**: Claude Code is Anthropic&\#x27;s command-line coding agent that can read files, run shell commands, edit code, and interact with external systems on behalf of a user. Auto mode is a recently introduced permission system that uses an automated safety classifier to decide whether a given action should proceed without prompting the user, replacing the older model of asking for human approval on every potentially risky command. Anthropic has promoted auto mode as a major security improvement, claiming it provides strong protection against prompt injection—a class of attacks where adversarial text embedded in files, web pages, or tool outputs hijacks the model&\#x27;s behavior. Because LLMs cannot structurally distinguish instructions from data, prompt injection remains one of the hardest unsolved problems in agent safety.

The results were published online in Nature Medicine on August 27, 2026. This trial marks a significant expansion of CAR T cell therapy beyond its established role in B-cell malignancies into autoimmune disease, specifically rheumatoid arthritis. ## [Cloudflare Saves 100TB of Memory by Optimizing 1.1.1.1 DNS Cache in Rust](https://blog.cloudflare.com/dns-cache-memory-optimization-1111/) ⭐️ 7.0/10

Cloudflare published a detailed engineering case study showing how five Rust-level memory optimizations to the DNS cache layout of their &\#x27;Big Pineapple&\#x27; system cut per-entry memory by 56%, freeing approximately 100TB of memory across their fleet. 1.1.1.1 is one of the world&\#x27;s largest public DNS resolvers serving billions of queries daily, so even per-entry micro-optimizations translate to massive infrastructure savings. This case study also offers a rare, practical look at systems-level memory engineering in Rust at hyperscale. The optimizations involved restructuring cache entry data layouts and allocation strategies in Rust to reduce per-entry overhead, with the gains compounded across billions of cached DNS records. At this scale, minor layout changes such as consolidating separate allocations into contiguous blocks yield outsized returns.

hackernews · Hacker News \(热门\) · Aug 27, 17:17 · [Discussion](https://news.ycombinator.com/item?id=49468083)

**Background**: DNS resolvers translate human-readable domain names \(like cloudflare.com\) into IP addresses that computers use to locate servers on the internet. To reduce latency, resolvers cache recent query results, but at the scale of a service like 1.1.1.1, the cache can hold billions of entries, each consuming memory. Even small per-entry savings become enormous when multiplied across the fleet. Rust is a systems programming language favored for performance-critical infrastructure because it provides memory safety guarantees without a garbage collector, though achieving minimal memory overhead still requires careful manual data structure design.
