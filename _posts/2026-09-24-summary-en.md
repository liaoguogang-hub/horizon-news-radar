## [Critical XSS Flaw in ansi2html.py Enables SourceHut Account Takeover](https://blog.arusekk.pl/posts/srht-account-takeover/) ⭐️ 8.0/10

Security researcher Arusekk disclosed a wormable cross-site scripting \(XSS\) vulnerability \(CVE-2026-92973\) in the ansi2html.py library used by SourceHut&\#x27;s build logs, allowing anyone who can inject text into a build log on builds.sr.ht to take over the accounts of users who view those logs. This vulnerability affects SourceHut, a widely-used open source development platform, and the underlying flaw resides in a shared Python library, meaning other applications that depend on ansi2html.py may also be exposed to the same attack vector. It highlights systemic supply chain risks in CI/CD ecosystems, where untrusted build output is rendered in a web browser. The flaw is classified as a stored XSS in build logs: an attacker can embed malicious payloads in ANSI escape sequences that ansi2html.py fails to sanitize when converting terminal output to HTML. Because the rendered logs are served on the same origin as SourceHut&\#x27;s authenticated session, the injected script can exfiltrate cookies or tokens, enabling full account takeover — and because the payload can be self-replicating \(&\#x27;wormable&\#x27;\), it can spread to other viewers automatically.

rss · Lobsters \(技术社区\) · Sep 24, 20:38

**Background**: Cross-site scripting \(XSS\) is a class of web vulnerability where attacker-controlled scripts are executed in a victim&\#x27;s browser, often enabling session hijacking. ansi2html.py is a Python utility that converts ANSI-colored terminal output \(commonly seen in CLI tools and CI build logs\) into HTML for browser display. SourceHut \(sr.ht\) is an open source, privacy-respecting development platform offering Git hosting, bug tracking, mailing lists, and continuous integration via builds.sr.ht. Because build logs frequently contain attacker-controllable output — such as compiler errors referencing attacker-supplied filenames or stack traces — rendering them as HTML without proper sanitization creates a classic injection sink.
