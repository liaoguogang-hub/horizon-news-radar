## [Rust team warns of targeted social engineering attacks on crate maintainers](https://simonwillison.net/2026/Sep/17/targeted-attacks-on-rustaceans/) ⭐️ 9.0/10

On September 17, 2026, Adam Harvey and the Rust crates security team issued an official warning about an ongoing targeted social engineering campaign against rust-lang members and owners of popular crates. Attackers arrange video calls framed as job interviews, project discussions, or contract opportunities, then trick targets into installing malicious software \(e.g., a fake audio codec\) or executing clipboard-based commands to compromise devices and publish malware on crates.io. This campaign has direct supply chain security implications for the entire Rust ecosystem, as a single compromised maintainer account can publish malicious crate versions that propagate to thousands of downstream projects. The August 2026 arrayref supply chain attack already demonstrated the real-world impact when crates like arrayref@0.3.10, internment@0.8.7, and append-only-vec@0.1.9 were compromised to inject build-time malware. The attack vector closely resembles the &\#x27;ClickFix&\#x27; social engineering technique, where victims are manipulated into manually pasting and executing malicious commands from their clipboard, bypassing traditional security controls. As a practical defense, Simon Willison recommends dependency cooldowns—delaying upgrades to new package releases by a few days so that supply chain attacks can be detected by others before they reach your build.

rss · Simon Willison \(AI 跨行业洞察\) · Sep 17, 23:59

**Background**: Rust crates are reusable code packages distributed via the official registry crates.io, and they form the backbone of Rust&\#x27;s dependency ecosystem, similar to npm for JavaScript or PyPI for Python. A supply chain attack occurs when malicious code is injected into a legitimate package, so that every project depending on it unknowingly inherits the malware. Social engineering via video calls is a relatively new escalation: instead of exploiting software vulnerabilities, attackers manipulate human targets into compromising their own machines, often using clipboard hijacking techniques that trick users into running terminal commands disguised as fixes or codecs.

## [Cloudflare Saves 100TB RAM via Mathematical Optimization](https://blog.cloudflare.com/saving-100-tb-of-ram-with-math/) ⭐️ 8.0/10

Cloudflare published a technical deep-dive detailing how mathematical optimization techniques saved 100TB of RAM in their production load balancing system. The article revisits optimization culture and demonstrates how principled engineering can yield massive memory savings at scale. At Cloudflare&\#x27;s scale, even small per-server memory reductions translate to enormous absolute savings across the fleet, directly impacting infrastructure costs and capacity. The article also signals a broader cultural shift back toward careful optimization as memory costs rise in the AI era. The savings involve replacing a massive lookup table of hash values per server with a more mathematically efficient selection scheme. The original approach stored N hash values per server to map request hashes to servers, and commenters suggested rendezvous hashing and other techniques that could reduce memory further still.

hackernews · Hacker News \(热门\) · Sep 18, 18:51 · [Discussion](https://news.ycombinator.com/item?id=49758580)

**Background**: Consistent hashing is a distributed-systems technique that maps both servers and requests onto a hash ring so that adding or removing a server only remaps a small subset of requests, making it ideal for load balancing at scale. Weighted variants account for servers of different capacities. Rendezvous hashing \(also called highest random weight\) is an alternative that ranks all servers per request without requiring a precomputed ring of hash values. Cloudflare operates a globally distributed network handling a significant fraction of internet traffic, so memory efficiency in their load balancers compounds across tens of thousands of servers.
