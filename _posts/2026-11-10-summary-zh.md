## [ANGPTL4 抑制在二期 b 试验中降低甘油三酯](https://www.nejm.org/doi/full/10.1056/NEJMoa2612463?ai=nejm&amp;af=R&amp;rss=currentIssue) ⭐️ 9.0/10

二期 b 临床试验 TYDAL-TIMI 78 显示，ANGPTL4 抑制剂 MAR001 在 12 周后显著降低了甘油三酯水平升高的成人患者的空腹甘油三酯。该研究在 2026 年美国心脏协会年会上公布，并同步发表于《新英格兰医学杂志》。 抑制 ANGPTL4 可能通过增强脂蛋白脂肪酶活性、改善甘油三酯清除，为高甘油三酯血症提供新的治疗选择。其心血管意义仍取决于脂质指标的改善能否转化为更好的临床结局，这需要后续研究加以验证。 MAR001 是一款由 Marea Therapeutics 资助开发的在研单克隆抗体；这项两部分、双盲二期 b 试验的注册号为 NCT07028749。已报告的有效性结果主要涉及第 12 周的空腹甘油三酯；现有摘要未提供足够信息来评估不良事件、不同剂量的效果或长期结局。

rss · NEJM · 最新文章 · 11月9日 02:00

**背景**: ANGPTL4 是一种血管生成素样蛋白，可抑制脂蛋白脂肪酶；这种酶参与分解循环脂蛋白颗粒中的甘油三酯。ANGPTL4 抑制剂旨在提高脂蛋白脂肪酶活性，从而降低甘油三酯水平。甘油三酯升高是一种公认的血脂异常，但指标下降本身并不能证明心血管事件会随之减少。

## [Survodutide 在肥胖心血管结局试验中达到安全性终点](https://www.thelancet.com/journals/lancet/article/PIIS0140-6736%2826%2902140-9/fulltext?rss=yes) ⭐️ 9.0/10

3 期 SYNCHRONIZE-CVOT 试验显示，在患有肥胖且已确诊心血管疾病、慢性肾病或心血管风险升高的成人中，survodutide 相较安慰剂未增加主要不良心血管事件的发生风险。该试验因此达到了主要心血管安全性终点。 这项结果为 survodutide 提供了心血管安全性方面的支持证据；它是一种同时作用于 GLP-1 受体和胰高血糖素受体的新型肥胖候选药物。该发现支持在心血管并发症风险尤其重要的人群中继续评估该药。 主要复合终点包括心血管死亡、非致死性卒中、非致死性心肌梗死、缺血相关冠状动脉血运重建以及心力衰竭事件。该研究是一项全球、随机、双盲、平行组、安慰剂对照、多中心且由事件驱动的 3 期试验；现有报告强调的是心血管安全性，而非证明其疗效优于安慰剂。

rss · The Lancet · 最新文章 · 11月9日 14:45

**背景**: Survodutide 是勃林殷格翰通过与 Zealand Pharma 合作开发的一种在研多肽，可同时激活胰高血糖素受体和 GLP-1 受体。心血管结局试验用于评估新药是否比安慰剂导致更多严重心血管事件，因此对于肥胖并已患疾病的患者尤为重要。尽管不同研究对主要不良心血管事件的定义可能存在差异，但 SYNCHRONIZE-CVOT 采用了涵盖心血管死亡、缺血事件、血运重建和心力衰竭的五部分复合终点。

## [深度学习步态模型可预测多系统健康特征](https://www.nature.com/articles/s41591-026-04725-8) ⭐️ 9.0/10

研究人员利用 3,328 名深度表型成人在五项运动任务中的三维骨骼运动数据，开发了步态基础模型。该模型的嵌入表示显著预测了 3,210 个表型目标中的 1,887 个，并提升了临床诊断和用药预测的表现。 这项研究表明，深度相机捕获的日常运动可成为超越运动障碍领域的广泛数字生物标志物。它有望支持涵盖多个身体系统的早期评估、诊断和用药决策，但在投入临床使用前仍需进一步验证。 该模型使用深度相机在五项运动任务中采集的骨骼运动数据进行训练。其预测能力在男性的全部 18 个身体系统以及女性的 18 个系统中的 17 个均有所提升，同时改善了临床诊断和用药预测。

rss · Nature Medicine · 11月9日 00:00

**背景**: 步态基础模型从运动数据中学习可复用的特征，并将其迁移至多个下游预测任务。在本研究中，学习到的嵌入表示将三维骨骼运动与临床及生理特征联系起来，从而构成数字生物标志物的基础。深度相机能够提供结构化的运动测量，无需参与者穿戴动作捕捉服或安装贴身传感器。

## [编程智能体获得现代 Web 开发指南](https://github.com/GoogleChrome/modern-web-guidance) ⭐️ 8.0/10

Chrome、Firefox、Edge 与 MDN 支持的贡献者发布了 Modern Web Guidance 技能 1.0，收录 200 多份关于现代浏览器 API 与 CSS 的精选指南。该项目还提供轻量级检索工具和确定性的旧式模式扫描器；据称，它将智能体在 200 项任务中的通过率从 55% 提升至 92%。 编程智能体虽然经常知道现代 Web 特性，却仍倾向于采用约 2019 年常见的 JavaScript 密集型写法。向智能体提供精选的平台原生指南，可以减少不必要的依赖、简化实现，并推动使用获得广泛支持的浏览器能力，但实际采用前仍需验证特性兼容性。 该软件包提供搜索和旧式扫描命令；扫描器使用 3 万个 GitHub 仓库训练，并报告在留出仓库上的平均精确率为 92%。其可检索知识包从最初的 500 MB 原生技术栈缩减为约 7 MB 的纯 JavaScript 包，本地搜索约为 10 毫秒，但部分推荐的 CSS 特性仍仅受部分浏览器支持。

hackernews · Hacker News \(热门\) · 11月10日 18:01 · [社区讨论](https://news.ycombinator.com/item?id=50443812)

**背景**: 现代浏览器特性可以用原生平台行为替代常见的自定义界面模式。例如，HTML 的 dialog 元素与 showModal\(\) 能够提供模态展示和焦点管理，CSS Custom Highlight API 则无需为文本范围添加大量 span 元素即可设置样式。field-sizing 属性还可以在浏览器支持条件允许时，让文本框随内容自动增长而无需 JavaScript。

文章建议将表示绝对事件的时间戳以 UTC 存储，仅在展示时转换为明确的时区。对于本地日程，应同时保存本地日期、时间和 IANA 时区标识，并在执行时解析潜在歧义。 区分绝对时刻与本地调度意图，可以避免跨地区混淆、夏令时错误和审计记录失真。该建议尤其适用于 CRM、预约系统、集成服务以及其他跨多个时区运行的应用程序。 JavaScript 的 Date.toISOString\(\) 可将绝对时刻序列化为 UTC 的 ISO 8601 字符串，Intl.DateTimeFormat 则可按 Asia/Kolkata 等指定时区展示。文章还建议区分接受时间、发生时间、接收时间和重试时间，使用后端时钟记录权威事件，并明确夏令时切换期间重复或不存在的本地时间的处理策略。

rss · Dev.to · 11月10日 17:00

**背景**: UTC 时间戳表示全球时间线上唯一且明确的绝对时刻，而本地挂钟时间只描述某个特定时区内的日期和时间。IANA 时区标识不同于固定的 UTC 偏移量，能够保留解析未来重复日程所需的夏令时规则。不同数据库提供多种日期时间类型，因此团队应选择能够保持预期时刻语义的类型，而不能假定所有列的时区行为完全相同。
