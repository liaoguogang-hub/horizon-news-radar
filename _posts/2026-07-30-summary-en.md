Unlike earlier versions that focused on upper-body or tabletop manipulation, this model is designed to drive entire humanoid robots as well as bi-arm robotic platforms. It positions Google alongside Anthropic and OpenAI as a leader in the broader race to give AI a physical presence in the real world. Gemini Robotics 2 is built as a vision-language-action model that converts visual and language input directly into motor commands, supporting full humanoid control as well as multi-robot collaboration. ## [GenAI Reshapes the Economics of Code Refactoring](https://martinfowler.com/articles/exploring-gen-ai/refactoring-economic-benefit.html) ⭐️ 8.0/10

Martin Fowler published a quantitative analysis arguing that generative AI tools dramatically lower the cost of refactoring code, making it far more economically viable than in the past and prompting a rethinking of best practices around code documentation and structure. Refactoring improves code readability, reduces complexity, and lowers long-term maintenance costs, but historically many organizations skip it because of high upfront expense. If GenAI genuinely shifts this calculus, it could change how engineering teams allocate budget between new features and code health, and it validates long-ignored software craftsmanship principles under a new label. The article is grounded in specific, measurable claims rather than vague AI hype, with McKinsey estimates cited elsewhere suggesting GenAI can reduce refactoring time by 20–30% and net-new code writing time by up to 45%. It has long been considered a best practice in software engineering, yet many companies underinvest in it because the immediate cost outweighs visible short-term benefits. Generative AI tools, such as large language model-based coding assistants, can now suggest or automatically apply refactoring changes by interpreting natural language instructions and analyzing existing code context.

## [Self-Replicating AI Worm Spreads Through Microsoft Copilot in Word](https://simonwillison.net/2026/Jul/29/ai-worming-through-word/#atom-everything) ⭐️ 8.0/10

Security researcher Håkon Måløy discovered a prompt injection worm targeting Microsoft Copilot in Word, where hidden instructions embedded in documents cause Copilot to copy the malicious payload into newly generated documents, enabling self-replication across files. This attack represents a significant escalation from static prompt injection to malware-like self-propagating behavior within AI-assisted workflows, potentially affecting any organization relying on Copilot for document drafting. The vulnerability was responsibly disclosed to Microsoft 144 days ago with no complete fix yet available. The attack uses hidden text \(such as white-on-white formatting\) within documents that Copilot interprets as legitimate instructions, then copies into output documents as new carriers. The technique works even without the attacker&\#x27;s original document being present in subsequent workflows, and Microsoft has not yet produced a mitigation covering the full class of attack.

rss · Simon Willison \(AI 跨行业洞察\) · Jul 29, 18:43

**Background**: Prompt injection is a class of attack where adversarial text is crafted to manipulate AI models into ignoring their original instructions and following attacker-controlled commands instead. OWASP has ranked prompt injection as a top security risk for LLM-based applications in 2025. Microsoft Copilot in Word is an AI assistant integrated into Microsoft 365 that uses large language models to help users draft and edit documents, and it can use other open documents as source material—creating an attack surface where malicious instructions in those documents may be interpreted as legitimate user requests.

The research was conducted in partnership with ETH Zurich, Tel Aviv University, and the University of Haifa.
