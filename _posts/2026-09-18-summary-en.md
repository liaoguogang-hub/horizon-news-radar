## [Targeted Social Engineering Attacks Hit Prominent Rust Maintainers](https://simonwillison.net/2026/Sep/17/targeted-attacks-on-rustaceans/) ⭐️ 9.0/10

The Rust Security Response Team has issued an alert about an ongoing social engineering campaign targeting rust-lang members and owners of popular crates, using fake video calls to trick them into installing malware or executing clipboard-injected commands. The campaign has already succeeded in compromising crates including arrayref \(v0.3.10\), append-only-vec, and internment on August 20, 2026, with attackers publishing a typosquatted proc-macro1 dependency that executed a remote payload at build time. This is a critical supply-chain threat because nearly every modern software project depends on open-source packages, meaning a single compromised maintainer account can poison thousands of downstream applications. The Rust ecosystem is especially exposed given its growing footprint in systems programming, and the use of convincing deepfake-style video calls marks an escalation in attacker tradecraft. The arrayref attack began at 01:17 UTC on August 20 with the creation of a GitHub account impersonating David Tolnay, followed by publication of malicious proc-macro1 versions; the poisoned arrayref 0.3.10 was released at 07:15 UTC while clean versions 0.3.5–0.3.9 were yanked to force adoption. The recommended defense is dependency cooldowns—delaying upgrades to new releases by a few days to allow time for the community to detect malicious versions.

rss · Simon Willison \(AI 跨行业洞察\) · Sep 17, 23:59

**Background**: crates.io is the official package registry for the Rust programming language, and packages \(called &\#x27;crates&\#x27;\) are typically pulled in as transitive dependencies, meaning developers often automatically inherit code from dozens or hundreds of packages they have never audited. A supply chain attack in this context means compromising a legitimate package so that downstream builds silently execute attacker-controlled code during compilation. The current campaign appears to use a ClickFix-style social engineering technique, where victims are lured into running commands via fake video-call pretexts such as missing audio codecs. Notable prior supply-chain incidents in other ecosystems, such as the xz-utils backdoor and the npm event-stream compromise, have shown that even single maintainer compromises can have ecosystem-wide blast radius.

## [Laser Fault Injection Bypasses RP2350 Secure Debug](https://donjon.ledger.com/blog/rp2350-secure-debug-laser-fault-injection/) ⭐️ 8.0/10

Ledger Donjon researchers demonstrated a photon-emission-guided laser fault injection attack on the Raspberry Pi RP2350 microcontroller that bypasses its secure debug protections by setting two specific bits to restore secure debug access on an A4 stepping chip. The attack requires physical access, destructive decapsulation of the chip, and approximately $250,000 of specialized laboratory equipment. The RP2350 was considered an attractive secure enclave option for applications like Yubikey alternatives, making this attack significant for the embedded security ecosystem. This research highlights the ongoing arms race between hardware attackers and defenders, and the findings will likely inform stronger protections in future chip generations. The attack used differential photon-emission microscopy to localize debug enable register activity, then SWD-guided laser injection to flip the necessary bits. Community members noted that while Ledger&\#x27;s $250k estimate is accurate for initial discovery, replicating such attacks in a home lab could cost under $10k using tools like the PicoEMP instead of commercial alternatives like the ChipShouter.

## [Cache-to-Cache: Direct LLM Semantic Communication via KV-Cache Fusion](https://arxiv.org/abs/2510.03215) ⭐️ 8.0/10

A 2025 paper introduces Cache-to-Cache \(C2C\), a new paradigm that enables direct semantic communication between large language models by projecting and fusing the KV-cache of a source model with that of a target model using a neural network. This allows LLMs to share contextual information without generating intermediate tokens. This represents a potential paradigm shift in multi-model AI systems, as it bypasses the traditional approach of converting model internals back into text for communication. It could significantly impact inference architectures, enable more efficient multi-agent systems, and open new possibilities for model collaboration at the representation level rather than the token level. The C2C method uses a neural network to project and fuse KV-caches between different LLMs, enabling direct semantic transfer. The approach fundamentally rethinks inter-model communication by operating on attention-level data structures rather than generated text tokens.

rss · Hacker News \(热门\) · Sep 18, 18:55

**Background**: KV-cache is a mechanism in transformer-based language models that stores key-value pairs from previous attention computations, enabling faster token generation during inference by reusing internal attention data. Traditional inter-model communication requires one model to generate text tokens that are then fed as input to another model, which involves lossy conversion through the token space. Semantic communication, a concept from information theory, aims to transmit meaning directly rather than bit-perfect reproductions, and applying this concept to LLM-to-LLM communication via cache layers is a novel research direction.

## [Four Linux Kernel Local Privilege Escalation Vulnerabilities Disclosed](https://seclists.org/oss-sec/2026/q3/822) ⭐️ 8.0/10

Security researcher Asim Manizada disclosed four Linux kernel local privilege escalation \(LPE\) vulnerabilities—DirtyAH6 \(CVE-2026-80844\), TUNderflow \(CVE-2026-81000\), PPPoEject \(CVE-2026-68121\), and DiagSpill \(CVE-2026-74469\)—with public exploits now available and upstream fixes released. The underlying bugs have existed in the kernel for 10 to 21 years, affecting long-standing networking code in components such as the IPv6 Authentication Header \(XFRM/IPsec\), TUN/TAP drivers, PPP over Ethernet, and diagnostic sockets. These are local-to-root privilege escalation flaws in the Linux kernel, meaning any unprivileged user or process on an affected system can potentially gain full root control, severely compromising multi-tenant servers, container hosts, and any Linux desktop or server exposed to untrusted local users. Because public exploit code is now circulating, systems running unpatched kernels face imminent risk of compromise. Three of the four vulnerabilities \(DirtyAH6, TUNderflow, PPPoEject\) require unprivileged user namespaces to exploit, while DiagSpill does not, making it the most accessible to attackers. PPPoEject stems from \`pppoe\_sendmsg\(\)\` retaining a stale pointer after the underlying device callback reallocated the socket buffer; the DirtyAH6 fix commit credits custom AI tooling, highlighting a growing trend of LLM-assisted vulnerability discovery.

rss · Lobsters \(技术社区\) · Sep 18, 07:57

**Background**: A local privilege escalation \(LPE\) vulnerability allows a user who already has some level of access to a system to elevate their privileges—typically to root—exploiting bugs in the operating system kernel. Linux user namespaces are a kernel feature that lets unprivileged users create isolated environments, but they have historically been a stepping stone for LPE exploits by providing controlled access to kernel interfaces. The affected subsystems—XFRM/IPsec for IPv6 security, TUN/TAP virtual network devices, PPPoE for broadband connections, and netlink-based diagnostic sockets—are all part of Linux&\#x27;s networking stack, a perennial source of kernel bugs due to its complexity and pointer-heavy memory management.
