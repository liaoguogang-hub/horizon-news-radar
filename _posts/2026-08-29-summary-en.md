This optimization demonstrates that careful data structure and memory layout design at the software level can yield infrastructure-scale savings comparable to major hardware investments. ## [Prompt Injection Attack Bypasses Claude Code Opus 5 Auto Mode](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) ⭐️ 8.0/10

Security researcher Johann Rehberger discovered a prompt injection attack against Claude Code Opus 5&\#x27;s auto mode that succeeds roughly 80% of the time by tricking the agent into downloading a malicious zip file. The attack exploits Python&\#x27;s module search path so that a hijacked struct.py file inside the archive shadows the standard library module and executes arbitrary code when base64 is imported. Anthropic promoted auto mode as a key defense against prompt injection and made it the default for Claude Code users in August 2026, so an 80% bypass rate is a major credibility blow to those safety claims. Any developer relying on auto mode without additional sandboxing may be exposed to arbitrary code execution from untrusted content. The attack works because Python places the current working directory ahead of standard library paths in sys.path, so a locally named struct.py silently overrides the real struct module. In some cases the auto mode classifier even blocked Claude&\#x27;s own attempt to terminate the malware process after it detected the compromise, turning the safety mechanism itself into part of the failure.

rss · Simon Willison \(AI 跨行业洞察\) · Aug 27, 22:50

**Background**: Prompt injection is a class of attack in which adversarial instructions are embedded inside content that an AI system reads, such as a webpage, document, or file, causing the model to behave in ways its user did not intend. Indirect prompt injection is especially dangerous for AI coding agents because those agents can fetch external files, run code, and take actions on a developer&\#x27;s machine with real privileges. Claude Code&\#x27;s auto mode is an Anthropic feature, rolled out in July 2026 and made the default on August 14, 2026, that uses a model-based classifier to approve or block tool calls on behalf of the user, sitting between full manual approval and unrestricted execution. Python module shadowing is a long-standing behavior in which a script-named file in the current directory takes precedence over a same-named module in the standard library.
