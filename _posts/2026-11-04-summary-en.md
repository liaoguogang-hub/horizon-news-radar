## [Debian apt Vulnerability Enables Root Code Execution via MITM](https://lists.debian.org/debian-security-announce/2026/msg00526.html) ⭐️ 9.0/10

Debian disclosed an apt security vulnerability in which apt can merge two package downloads after an HTTP redirect gives them the same URI. Improper handling of resumed HTTP downloads can allow a man-in-the-middle attacker to replace a package after verification, leading to arbitrary code execution as root. The flaw threatens the integrity of Debian and Ubuntu package installation and update workflows, potentially turning a compromised network connection into privileged software supply-chain tampering. Successful exploitation could give an attacker control over systems at the highest local privilege level. The vulnerable behavior depends on apt merging downloads associated with the same URI following an HTTP redirect and mishandling a resumed HTTP download. The advisory specifically describes package replacement after verification and does not, in the provided search results, identify a CVE identifier or affected package versions.

rss · Lobsters \(技术社区\) · Nov 4, 13:36

**Background**: APT is the package manager used to install, upgrade, and remove software on Debian and related distributions such as Ubuntu. It retrieves packages and related metadata over the network, while HTTP redirects and interrupted downloads can cause apt to resume or combine transfers. Because package installation normally grants root privileges, tampering with a verified package can have system-wide consequences.

## [Go Introduces a New JSON API](https://go.dev/blog/jsonv2) ⭐️ 8.0/10

Go introduced \`encoding/json/v2\`, a redesigned JSON API intended to modernize the standard library with improved performance and more consistent behavior. The existing \`encoding/json\` package remains available as the version 1 API. JSON is a core interchange format for Go services, so changes to its standard-library API can affect a large ecosystem of applications, libraries, and developers. The new package could improve throughput and correctness while making migration from the original API an important concern. The version 2 design changes some serialization semantics, including how nil slices and maps are represented by default, and the original package&\#x27;s behavior otherwise remains unchanged. Go 1.25 first exposed the proposal experimentally, while the implementation is associated with Go 1.27, where the experimental module can alias the standard-library version when the \`goexperiment.jsonv2\` build tag is enabled.

hackernews · Hacker News \(热门\) · Nov 4, 17:52 · [Discussion](https://news.ycombinator.com/item?id=50369106)

**Background**: Go&\#x27;s original \`encoding/json\` package provides the familiar high-level functions for encoding Go values as JSON and decoding JSON into Go values. The version 2 API separates higher-level JSON operations from lower-level JSON text and token processing, while preserving the version 1 package for compatibility. Community discussion also explored schema-specialized and SIMD-accelerated parsing as ways to improve JSON performance further.

## [Anthropic Advances Cryptographically Provable LLM Inference](https://www.anthropic.com/research/provable-inference) ⭐️ 8.0/10

Anthropic introduced FlashProve, a research prototype for cryptographically proving that a provider committed to particular model weights actually generated each response. The system targets large Mixture-of-Experts language models and reports substantial efficiency improvements over earlier zero-knowledge approaches, though verification remains costly. Provable inference could give customers and auditors evidence that a closed-model provider did not substitute the advertised model, without exposing proprietary weights or intermediate computations. It may strengthen assurances for regulated or sensitive deployments, but its compute overhead and reliance on specialized infrastructure could limit broad adoption. According to the discussion, the provider publishes a roughly 6.5 MB commitment, which remains usable for about 16 million requests, and generates one proof per request; checking a proof takes about 17 seconds on 24 threads and 21 seconds on one thread. The prototype is not maintained, and alternative approaches include rerunning deterministic open-weight inference, cross-checking multiple providers, lightweight statistical verification, or signed responses.

hackernews · Hacker News \(热门\) · Nov 4, 17:17 · [Discussion](https://news.ycombinator.com/item?id=50368626)

**Background**: A zero-knowledge proof can demonstrate that a computation was performed correctly without revealing the underlying secret data. In this setting, the secret may be a proprietary model&\#x27;s weights, while the proof establishes which committed model produced a response and that the claimed inference occurred. This differs from ordinary audits because verification is cryptographic and can in principle be performed independently by a client.

Hy4 applies that open-model approach to coding and game-engine workflows, while HyCell and HyPDE target scientific domains. A mixture-of-experts model activates only a subset of its parameters for each token, which can reduce inference costs relative to activating an entire dense model of comparable total size.
