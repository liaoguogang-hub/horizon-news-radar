## [LLM 辅助的 Lean 证明使 zstd 解码器形式化验证成为现实](https://www.imperialviolet.org/2026/07/26/zstd-lean.html) ⭐️ 8.0/10

Google 的 Adam Langley 展示了 LLM 辅助的 Lean 定理证明使得对 zstd 解码器进行形式化验证变得切实可行，并论证了证明自动化已经跨越了一个有意义的应用门槛。 形式化验证历来成本高昂，约为正常开发成本的 20 倍，因此仅被用于最关键的代码路径。如果 LLM 能够可靠地自动化证明撰写的大部分工作，验证将在经济上对更多软件变得可行，从而重塑安全工程以及漏洞预防的经济学。 该案例研究聚焦于一个真实的、并非平凡的 zstd（Zstandard）解码器——这一压缩库最初由 Facebook 开发。作者指出形式化验证与常规开发之间的成本比例，并将其作为证据，表明该领域已达到一个临界点，LLM 驱动的自动化能显著减少人工撰写证明的工作量。

hackernews · Hacker News \(热门\) · 7月26日 20:53 · [社区讨论](https://news.ycombinator.com/item?id=49062291)

**背景**: 形式化验证使用像 Lean 这样的定理证明器，以数学方式证明软件行为完全符合规约，而非仅仅依赖测试。Lean 是一个自 2013 年起开发的开源证明助手，它将函数式编程与依赖类型相结合，允许在编译时表达并检查程序的性质。zstd（Zstandard）是 Facebook 开发的被广泛使用的高速压缩算法，其解码器处理熵编码与帧解析——这些逻辑非常适合形式化规约，但历来对其进行完整验证的成本过高。

## [深入调查转售 LLM API Token 的灰色市场](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 8.0/10

Matt Lenhard 进行的一项调查（由 Simon Willison 转发）揭示了一个蓬勃发展的灰色市场——主要集中在中国——转售商通过聚合利用免费试用、未受保护的客服机器人接口、盗用的信用卡以及拒付攻击获取的凭证，以折扣价出售 LLM API 的访问权限。这些转售商使用合法的开源代理工具运营，主要是一 one-api 及其维护更活跃的分支 new-api，这些工具可以将请求负载均衡到多个 API 密钥上。 这个生态系统对 LLM 提供商的收入和安全构成直接威胁，同时也会因盗卡欺诈给受害者带来经济损失，并通过滥用免费试用让合法用户承担额外成本。它还增加了独立开发者公开部署 LLM 驱动应用的风险，因为任何新发现的未受保护接口都可能很快通过这个中转市场被变现牟利。 这些中转服务的买家通常追求更便宜的 token、绕过地理限制，或收集输出数据用于模型蒸馏（用大模型的输出来训练小模型的技术）。Simon Willison 特别呼吁 LLM 厂商提供严格且用户可配置的按密钥支出上限（例如按时间段设置固定的美元阈值），使滥用行为带来的损失可控且可预测。

rss · Simon Willison \(AI 跨行业洞察\) · 7月26日 19:30

**背景**: LLM API 代理是位于终端用户和一个或多个上游模型提供商之间的服务器，负责转发请求并处理负载均衡、密钥轮换和协议转换等任务。一 one-api 和 new-api 等开源项目是用于这些用途的合法工具，被广泛部署，但它们聚合大量凭证并转售访问权限的能力使其成为上述滥用行为的理想基础设施。在本文语境中，拒付攻击通常指欺诈者用盗刷的信用卡为 LLM 账户充值、消费 token，然后再向银行发起争议——使 API 提供商承担损失，而转售商则保留利润。
