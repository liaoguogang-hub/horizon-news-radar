## [Debian apt 漏洞可被中间人利用以 root 身份执行代码](https://lists.debian.org/debian-security-announce/2026/msg00526.html) ⭐️ 9.0/10

Debian 披露了 apt 的一个安全漏洞：当 HTTP 重定向使两个软件包下载具有相同的 URI 时，apt 可能将它们合并。对 HTTP 续传下载的不当处理可让中间人攻击者在验证后替换软件包，最终以 root 身份执行任意代码。 该漏洞威胁 Debian 和 Ubuntu 软件包安装及更新流程的完整性，攻击者只需控制网络连接便可能篡改软件供应链。若利用成功，攻击者可在目标系统上获得最高的本地权限。 漏洞涉及 apt 在 HTTP 重定向后将具有相同 URI 的下载合并，以及对 HTTP 续传下载的错误处理。公告明确指出攻击者可在验证后替换软件包，但提供的搜索结果未列出 CVE 编号或受影响的软件包版本。

rss · Lobsters \(技术社区\) · 11月4日 13:36

**背景**: APT 是 Debian 及 Ubuntu 等相关发行版用于安装、升级和卸载软件的包管理器。它通过网络获取软件包及相关元数据，而 HTTP 重定向和中断下载可能使 apt 续传或合并传输内容。由于软件包安装通常具有 root 权限，攻击者篡改已验证的软件包可能影响整个系统。

## [白宫网络发现住宅代理](https://layer3intel.com/blog/residential-proxies-white-house-network) ⭐️ 8.0/10

一份报告称，在连接到白宫网络的设备上检测到了住宅代理流量。这一发现表明，受入侵的消费设备可能一直在作为代理运行，而白宫网络环境也可能接触敏感政府系统。 住宅代理可以利用看起来合法的住宅 IP 地址隐藏恶意流量，使僵尸网络活动更难追踪和阻断。在政府网络中发现此类代理，引发了外界对命令与控制活动、横向访问，以及受控设备被用于欺诈、抓取或其他更危险任务的担忧。 现有新闻摘要没有说明受影响设备、检测方法、代理运营方、恶意软件家族或活动持续时间，也未提供原始研究。由于受控设备可通过互联网服务提供商分配的真实地址通信，仅依赖 IP 黑名单和数据中心网络检查可能漏检，因此检测可能需要结合行为分析、威胁情报或蜜罐系统。

hackernews · Hacker News \(热门\) · 11月4日 20:45 · [社区讨论](https://news.ycombinator.com/item?id=50371246)

**背景**: 住宅代理通过使用消费者拥有的联网设备转发流量，使请求看起来像是从真实住宅地址发出。代理运营方通常会招募或入侵设备，并将这些设备组成类似僵尸网络的大型网络，用于网页抓取、欺诈以及规避地域或信誉限制。由于流量借助普通消费级基础设施运行，它可能混入正常网络活动，使简单过滤措施失效。

## [Go 推出全新 JSON API](https://go.dev/blog/jsonv2) ⭐️ 8.0/10

Go 推出了重新设计的 JSON API \`encoding/json/v2\`，旨在通过更快的性能和更一致的行为实现标准库的现代化。现有的 \`encoding/json\` 包继续保留，作为第一版 API 使用。 JSON 是 Go 服务中常用的核心数据交换格式，因此标准库 API 的变化会影响大量应用、库和开发者。新包有望提升吞吐量与正确性，但从原有 API 迁移过来也将成为开发者需要面对的重要问题。 第二版改变了一些序列化语义，例如默认情况下如何表示空值切片和映射；原有包的其他行为则保持不变。Go 1.25 首次以实验形式公开该方案，而相关实现对应 Go 1.27；启用 \`goexperiment.jsonv2\` 构建标签后，实验模块会映射到标准库中的实现。

hackernews · Hacker News \(热门\) · 11月4日 17:52 · [社区讨论](https://news.ycombinator.com/item?id=50369106)

**背景**: Go&\#x27;s original \`encoding/json\` package provides the familiar high-level functions for encoding Go values as JSON and decoding JSON into Go values. The version 2 API separates higher-level JSON operations from lower-level JSON text and token processing, while preserving the version 1 package for compatibility. Community discussion also explored schema-specialized and SIMD-accelerated parsing as ways to improve JSON performance further.

## [全球扩大气候健康行动可带来经济与财政效益](https://www.thelancet.com/journals/lancet/article/PIIS0140-6736%2826%2902057-X/fulltext?rss=yes) ⭐️ 6.0/10

《柳叶刀》评论文章指出，气候变化造成的疾病负担及相关成本正在扩大，需要在全球范围内扩大气候健康行动。文章将其中许多干预措施视为促进健康、捍卫人权、推进气候正义与健康公平的全球公共产品。 加大气候健康政策投入，既可减少可避免的疾病和经济损失，也可能帮助政府控制公共卫生支出。 这一路径还将气候适应与人权保障以及更公平的健康结果联系起来。 评论将气候健康行动定义为卫生部门及影响健康决定因素的其他部门所采取的政策、方案或干预措施，用于预估、预防、准备、应对或减轻气候变化带来的健康风险。 这主要是一项高层次政策倡议，并非针对具体干预措施的方法学研究或量化评估。

rss · The Lancet · 最新文章 · 11月4日 08:00

**背景**: 气候变化可通过高温、空气污染、传染病、粮食不安全及其他对气候敏感的风险影响健康，若行动延误，损失可能不断累积。 健康影响归因研究旨在估算人为气候变化所致的疾病负担，但美国疾病控制与预防中心指出，目前尚不存在用于预测这些影响的单一金标准。 因此，气候健康行动不仅涉及卫生系统，也涵盖影响健康决定因素的其他部门，包括旨在增强韧性并防止可避免伤害的政策。
