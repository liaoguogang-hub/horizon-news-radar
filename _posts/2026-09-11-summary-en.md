## [CHERIoT: Capability-Based Isolation for MMU-less Microcontrollers](https://queue.acm.org/doi/10.1145/3831361) ⭐️ 8.0/10

An ACM Queue article details how CHERIoT leverages hardware capability features to deliver strong memory isolation and compartmentalization on microcontroller-class devices that lack a traditional Memory Management Unit \(MMU\). The architecture, originating from Microsoft Research, enables fine-grained software compartmentalization directly through hardware-enforced capabilities rather than virtual memory. This matters because embedded and IoT devices typically lack MMUs yet face mounting security threats, and CHERIoT offers a practical path to memory safety and compartmentalization on these constrained platforms. It could significantly reduce attack surfaces in industrial, automotive, and consumer IoT systems where software vulnerabilities have had outsized real-world consequences. CHERIoT is built on the RISC-V Ibex core, extending the RV32EMCB instruction set with capability extensions. To accommodate microcontroller constraints, it uses a compact 65-bit capability format rather than the 129-bit capabilities used in larger CHERI implementations, and enforces that capability offsets are always non-negative to simplify metadata. Commercial adoption is already underway, with SCI Semiconductor announcing the ICENI CHERIoT-compatible microcontroller in 2024.

rss · Lobsters \(技术社区\) · Sep 10, 14:59

**Background**: A Memory Management Unit \(MMU\) is the hardware component typically responsible for translating virtual memory addresses to physical addresses and enforcing process isolation, but it is too large, power-hungry, and expensive for low-end microcontroller use cases. CHERI \(Capability Hardware Enhanced RISC Instructions\) is a research architecture developed by SRI International and the University of Cambridge that takes a different approach: it introduces unforgeable hardware capabilities that encode both a pointer and the permissions and bounds associated with it, enabling fine-grained memory protection at every memory access. CHERIoT is a specialization of CHERI designed specifically for microcontroller-class devices, where silicon area, power, and memory footprint are all at a premium.

Calif Research has publicly demonstrated WeWorm, a proof-of-concept zero-click worm that spreads through WeChat voice calls across both iOS and Android, hijacking accounts without the victim needing to answer or interact with their phone. The team, working with AI, discovered the underlying memory corruption bug in WeChat&\#x27;s VoIP stack and wrote the initial remote code execution exploit in about two days, with the full worm taking roughly one additional week to build. This demonstrates that AI-assisted vulnerability research has compressed the timeline for developing sophisticated, cross-platform mobile malware from months to days, dramatically lowering the barrier for producing offensive capabilities that previously required large, well-funded teams. The cross-platform nature of WeChat \(over a billion users\) and the zero-click vector mean billions of mobile users could be exposed if such techniques are replicated by malicious actors. The exploit targets a memory corruption vulnerability in WeChat&\#x27;s Voice-over-IP stack and succeeds even when the victim hears nothing upon answering. Calif researchers stated that AI handled most of the technical work, while human researchers provided strategic judgment on targeting and safe testing; Tencent confirmed the researchers&\#x27; findings.
