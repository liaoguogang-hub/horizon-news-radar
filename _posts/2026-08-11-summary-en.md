A reverse-engineering analysis reveals that the BlueMove DEX exploit on Sui, which drained approximately 714,000 SUI \(~$528,000\) on July 11, 2026, was caused by a cross-version reserve desynchronization vulnerability — not the previously reported arithmetic overflow or backdoor. This analysis exposes a novel attack vector specific to upgradeable smart contracts where multiple package versions remain callable simultaneously, a pattern unique to the Move/Sui ecosystem. ## [H3-metal: Native MiniMax-H3 Inference for Apple Silicon](https://github.com/antirez/h3.c) ⭐️ 7.0/10

antirez has released h3-metal, a native Metal/C implementation of the MiniMax-H3 video generation model optimized for Apple Silicon Macs, enabling fully local video inference without relying on cloud GPUs. The project currently includes experimental sparse attention support as an opt-in mode, based on hints from the MiniMax team about upcoming sparse attention capabilities. This is one of the first native, low-level implementations of MiniMax-H3 on Apple&\#x27;s Metal API, giving Mac users a path to run cutting-edge open-weight video generation locally on unified memory. It also highlights the growing viability of Apple Silicon as a platform for serious generative AI workloads, historically dominated by NVIDIA CUDA. The implementation is written in C and uses Metal for GPU acceleration, with antirez adding a --sparse-attention flag in response to community AMA discussions. Real-world usage reported in the thread shows generation is currently very slow — roughly an hour for a ~9-second 480p clip at 20 steps on an M5 Pro with 64GB, and about 1.5 hours for a 15-second 480p clip on an M4 Max with 128GB, leaving significant headroom for the planned sparse attention optimization to deliver meaningful speedups.

hackernews · Hacker News \(热门\) · Aug 11, 01:22 · [Discussion](https://news.ycombinator.com/item?id=49252179)

**Background**: MiniMax-H3 is an open-weight omni-modal model released by MiniMax that unifies text, image, video, and audio generation in a single architecture, capable of producing up to 15-second 2K-resolution videos with native stereo sound. Apple Silicon Macs feature Unified Memory Architecture \(UMA\), where CPU and GPU share the same memory pool, making them well-suited for large quantized models via Metal, Apple&\#x27;s low-level graphics and compute API. Sparse attention techniques for video diffusion models — such as Radial Attention and VMoBA — exploit spatio-temporal redundancy to drastically reduce the quadratic cost of attention over many frames, and are widely seen as the key to making local high-resolution video generation practical.

## [Chicken Scheme 6.0 Released with Full Unicode Support](https://code.call-cc.org/releases/6.0.0/NEWS) ⭐️ 7.0/10

An Editorial Expression of Concern is a formal but intermediate step between publication and retraction; it alerts readers while an investigation proceeds. The 2002 Nature Medicine paper in question demonstrated that co-expressing CDK4 with oncogenic Ras in human epidermal tissue generates invasive neoplasia resembling squamous cell carcinoma, a finding that has been influential in understanding how cell-cycle deregulation cooperates with oncogenic signaling. An Editorial Expression of Concern is a mechanism journals use to flag papers under investigation without yet issuing a formal retraction.
