## [DuckDB v2.0 预览版发布，Quack 远程协议成亮点](https://duckdb.org/2026/08/17/duckdb-20-highlights) ⭐️ 8.0/10

DuckDB v2.0 将于今年秋季发布，公开预览版展示了多项重大功能，包括 Quack 远程协议（支持客户端-服务器部署）、触发器、VARIANT 类型、异步 I/O、全新的 SQL 解析器以及全新的存储格式。 v2.0 里程碑标志着 DuckDB 从嵌入式分析引擎逐步成熟为更加通用的数据平台。通过 Quack 引入服务器模式，将其使用场景从单进程分析扩展到共享的多用户环境，拓宽了它与传统分析数据库的竞争空间。 Quack 以扩展方式实现，允许网络上任意两个 DuckDB 进程分别作为客户端和服务器，通过网络传输支持完整的 DuckDB 功能集，包括多个并发写入者。现有用户指出，对 memory\_limit 执行机制仍有顾虑，因为在配置了内存限制的情况下 DuckDB 仍可能被 OOM 杀死。

hackernews · Hacker News \(热门\) · 8月17日 13:46 · [社区讨论](https://news.ycombinator.com/item?id=49330781)

**背景**: DuckDB 是一个进程内 SQL 数据库管理系统，专为分析型（OLAP）工作负载而优化，常被拿来与 SQLite 类比，但设计目标聚焦于分析而非事务处理。它可以直接嵌入到应用程序中，无需外部依赖，并可原生查询 CSV、Parquet、JSON 等格式。即将发布的 v2.0 是其在嵌入式模型之外的一次重大能力扩展。

## [AI 生成的 Copilot Autofix 合并请求在 Snowflake 引入可利用漏洞](https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug) ⭐️ 8.0/10

Wiz 研究人员发现，Snowflake 某个代码仓库中由 GitHub Copilot Autofix 自动生成的拉取请求在 GitHub Actions CI/CD 工作流（jira\_issue.yml）中引入了模板注入漏洞，该漏洞可被利用以访问内部 Jira 工单和凭据。 这是一个真实案例，证明了 AI 生成的代码可能引入生产级安全漏洞，并且 AI 代理能够自主发现并利用这些缺陷。随着 AI 编程助手深度融入软件开发流程，这一事件凸显了组织面临的日益增长的安全风险。 该漏洞是一个脚本注入缺陷，原因是不可信输入在 GitHub Actions 的 \`run:\` 块中被展开时未进行正确转义。Wiz 的 Red Agent 自主构造了一个恶意的 Jira 工单标题，在模板展开时突破 echo 字符串的边界，并通过带外回调窃取了 Jira 凭据，整个过程无需人工干预。

hackernews · Hacker News \(热门\) · 8月17日 14:18 · [社区讨论](https://news.ycombinator.com/item?id=49331423)

**背景**: GitHub Copilot Autofix 是一个 AI 驱动的功能，可在拉取请求中自动为检测到的问题建议代码修复方案。GitHub Actions 是一个 CI/CD 平台，允许开发者使用 YAML 配置文件实现工作流自动化。此处的模板注入是指用户可控输入未经净化直接插入到 shell 命令中，从而允许攻击者执行任意代码的漏洞。Wiz 是一家云安全公司，其 Red Agent 是一款由 AI 驱动的攻击性安全工具，旨在自主发现并验证漏洞。

## [德国裁定苹果在应用追踪透明度框架中优待自家应用](https://www.bundeskartellamt.de/SharedDocs/Meldung/EN/Pressemitteilungen/2026/08_17_2026_Apple_ATTF.html) ⭐️ 7.0/10

德国联邦卡特尔局（Bundeskartellamt）认定苹果的应用追踪透明度（ATT）框架对第三方应用施加了比自家应用更严格的追踪权限提示，从而构成了不公平的竞争优势。苹果已同意将这些提示统一化，使所有应用（包括其第一方应用）使用相同的追踪同意对话框。 这一裁定强化了以下原则：隐私功能不能被用作反竞争自我偏好的工具，并为欧盟及其他地区如何审查平台级隐私控制开创了先例。它将影响欧盟数百万 iOS 用户，他们将在所有应用中看到一致的同意体验，同时也向其他守门人平台发出信号：第一方与第三方应用之间的差异化对待将引发监管干预。 在原始的 ATT 框架下，第三方应用需要通过苹果的 ATT API 显示醒目的追踪权限提示，而苹果自家的应用则可以进行第一方追踪而无需此类提示，仅依赖 App Store 隐私标签中的披露。苹果现在将使其自家应用的提示与相同标准对齐，但确切的范围——是否仅限于欧盟还是全球范围——仍有待澄清。
