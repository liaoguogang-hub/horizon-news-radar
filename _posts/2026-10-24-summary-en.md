## [Brotli Flaw Spreads Beyond Node2Shell](https://www.aikido.dev/blog/python-packages-vulnerable-node2shell-brotli-cve-2026-111497) ⭐️ 8.0/10

CVE-2026-111497, initially associated with Node.js and called Node2Shell or HTTP2Shell, is also known as Broccoli2Shell and affects multiple HTTP libraries and applications that decode attacker-controlled Brotli data. In applicable request paths, the flaw has unauthenticated remote code execution implications, while patched Node.js releases include 22.23.4, 24.22.1, and 26.12.1. The naming understates the attack surface: the underlying defect is in Brotli decoding rather than HTTP/2 alone, so exposure is not limited to Node.js or servers that decode compressed request bodies. Applications may also be vulnerable when their code or libraries decompress Brotli responses fetched from untrusted servers. Exploitability depends on the affected component actually decoding attacker-controlled Brotli data and on the application&\#x27;s request-compression configuration. Patching the runtime covers response decoding performed by Node.js itself, but applications and libraries need separate assessment and updated releases where required.

hackernews · Hacker News \(热门\) · Oct 24, 08:06 · [Discussion](https://news.ycombinator.com/item?id=50219177)

**Background**: Brotli is a compression format commonly used to reduce the size of HTTP payloads. A maliciously crafted compressed payload can exploit a flaw in a decoder before the application validates the decoded content, making vulnerable decompression code a high-impact attack surface. The official Node.js advisory notes that Node.js does not decode Brotli by itself; exposure arises when application code or a library invokes decompression on attacker-controlled data.
