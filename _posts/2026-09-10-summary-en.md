## [JEP 544 Brings Ahead-of-Time Compilation to the JDK](https://openjdk.org/jeps/544) ⭐️ 8.0/10

JEP 544 proposes adding native ahead-of-time \(AOT\) code compilation directly into the JDK, allowing Java applications to be pre-compiled into native executables to reduce startup time and resource consumption. This JEP addresses one of Java&\#x27;s longest-standing weaknesses in cloud-native and serverless environments, where slow JVM startup and warm-up times have traditionally pushed workloads toward Go, Rust, or GraalVM Native Image. The proposal is tracked under JDK-8380476 and is blocked by JDK-8382711, which adds AOT code dumping support to the Shenandoah garbage collector, indicating that GC integration is a critical implementation dependency.

rss · Hacker News \(热门\) · Sep 10, 17:30

**Background**: Traditional JVMs rely on just-in-time \(JIT\) compilation, which translates Java bytecode into machine code at runtime, enabling aggressive optimizations but incurring slow startup. Ahead-of-time \(AOT\) compilation pre-translates bytecode into native code before execution, dramatically reducing startup time and memory footprint at the cost of losing some runtime optimization opportunities. Project Leyden has been the broader OpenJDK initiative exploring AOT techniques, and external solutions like GraalVM Native Image and frameworks such as Quarkus have already demonstrated that AOT can cut startup times by 75% or more.

## [DOOM Runs Entirely Inside the Linux Kernel via eBPF Fibers](https://ayles.github.io/doom-in-kernel/) ⭐️ 8.0/10

A developer has successfully implemented the classic first-person shooter DOOM entirely within the Linux kernel using eBPF fibers, showcasing an extraordinary feat of low-level programming. The project demonstrates that a complex graphics application can run in the highly constrained kernel environment by leveraging eBPF&\#x27;s sandboxed execution capabilities. This project highlights the surprising flexibility and power of eBPF as a programming platform, pushing it far beyond its intended use cases like networking, tracing, and security. It serves as a creative demonstration of kernel internals and eBPF capabilities, inspiring developers to think about unconventional applications of constrained computing environments. The implementation uses eBPF fibers—a mechanism for cooperative multitasking within the kernel—to handle the game&\#x27;s execution flow. Running DOOM in the kernel requires bypassing typical kernel restrictions on memory allocation, graphics rendering, and input handling, all within eBPF&\#x27;s sandboxed and verified execution model.

rss · Hacker News \(热门\) · Sep 9, 17:31

**Background**: eBPF \(extended Berkeley Packet Filter\) is a revolutionary Linux kernel technology that allows sandboxed programs to run inside the kernel without modifying kernel source code or loading kernel modules. It was originally designed for network packet filtering but has expanded to use cases including observability, tracing, security, and networking \(e.g., XDP, Cilium\). DOOM, released in 1993, is a legendary first-person shooter known for running on extremely constrained hardware—from toasters to printers—making it a popular benchmark for creative computing demonstrations.

Calif Research has demonstrated WeWorm, the first zero-click worm that spreads through WeChat calls across both iOS and Android, developed with AI assistance in about a week after finding the underlying bug and writing the initial remote code execution \(RCE\) exploit in roughly two days. This research highlights a paradigm shift in exploit development: AI is dramatically compressing the timeline from vulnerability discovery to weaponized worm, capabilities that previously took large teams months to build. It lowers the barrier for less-skilled actors and raises the stakes for mobile messaging platforms that billions of users rely on daily. The exploit requires no user interaction — victims do not need to answer the call, and even if they do, they hear nothing while it still succeeds. rss · Simon Willison \(AI 跨行业洞察\) · Sep 10, 00:56

**Background**: A zero-click exploit is a type of attack that compromises a device without any action from the user, such as tapping a link or opening a file, making it especially dangerous because there is no visible warning sign. A worm is malware that can self-replicate by propagating from one victim to another, amplifying its reach automatically. WeChat, owned by Tencent, is one of the world&\#x27;s largest messaging platforms with over a billion users, making it a high-value target. Calif Research&\#x27;s broader point is that generative AI tools are increasingly capable of handling the technical heavy lifting in exploit development, shifting the bottleneck from engineering skill to strategic judgment about what to target.

This kind of low-level hardware archaeology provides rare insight into how CISC processors implemented complex instruction sets in the 1980s through microcoded control units. Modern processors like Intel and AMD now encrypt their microcode to prevent exactly this kind of reverse engineering, making work on older unencrypted designs like the V20 especially valuable.

rss · Lobsters \(技术社区\) · Sep 10, 10:44

**Background**: Microcode is a layer of lower-level instructions stored in a CPU&\#x27;s control store \(typically on-chip ROM\) that implements the visible instruction set architecture \(ISA\).
