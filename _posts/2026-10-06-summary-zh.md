## [论文宣称实现亚二次 3SUM 与亚三次 APSP 算法](https://arxiv.org/abs/2610.06783) ⭐️ 9.0/10

一篇新的 arXiv 论文（编号 2610.06783）宣称给出了 3SUM 问题的亚二次时间算法以及全源最短路径（APSP）问题的亚三次时间算法。如果这些结论成立，将直接推翻细粒度复杂性理论中两个最核心的猜想——3SUM 猜想和 APSP 假设。 3SUM 猜想和 APSP 假设是数十个算法、数据结构和计算几何领域条件性硬度结果的理论基石；推翻它们将迫使细粒度复杂性理论进行全面修正。即便新算法中包含实际上大到无法使用的常数，其理论意义对该领域而言仍然是颠覆性的。 根据相关评论，新算法中出现的常数过大，不具有任何实际应用价值，其影响主要体现在亚三次等价关系的理论层面，而非现实世界的运行效率。鉴于这一结论极具颠覆性，在经过同行评审之前，arXiv 上的这篇论文（编号 2610.06783）的结论应审慎对待。

rss · Hacker News \(热门\) · 10月6日 12:31

**背景**: 细粒度复杂性是计算复杂性理论的一个子领域，致力于确定 P 类内问题的精确时间复杂度，而不仅仅是判断其是否属于多项式时间可解。在该领域中，3SUM 猜想（断言判断 n 个数的集合中是否存在三个数之和为零需要Ω\(n²\)时间）和 APSP 假设（断言在字 RAM 模型下计算加权图的全源最短路径需要Ω\(n³\)时间）处于核心地位。这些猜想通过细粒度归约被用来为大量其他问题建立条件性下界，是现代复杂性研究的基石。

## [光遗传学获诺贝尔奖：用光控制神经元](https://arstechnica.com/science/2026/10/controlling-the-brain-with-light-earns-a-physiology-nobel/) ⭐️ 9.0/10

诺贝尔生理学或医学奖已授予光遗传学，这是一项利用光控制神经元的革命性技术，其起源可追溯至在绿藻中发现的感光蛋白。 这一里程碑式的认可验证了数十年来变革性的神经科学研究成果，凸显了一项从根本上改变了科学家研究神经回路方式的技术，并可能加速未来在脑部疾病和治疗方面的发现。 光遗传学依赖于通道视紫红质（channelrhodopsins），这些光控离子通道最初发现于单细胞绿藻莱茵衣藻（Chlamydomonas reinhardtii），后被工程化导入神经元，使其能够对光做出精确的激活或抑制反应。

rss · Ars Technica · 10月5日 17:59

**背景**: 光遗传学结合了光学与遗传学技术，用光来控制特定的神经细胞。该技术始于在趋光性绿藻中发现的通道视紫红质，这些生物利用这些蛋白质实现光趋性运动——即对光做出反应的运动。研究者意识到这些感光蛋白可以被导入神经元，从而使科学家能够以极高的精确度开启或关闭特定的脑细胞。这推动了神经回路功能研究的重大突破，帮助我们理解行为、记忆以及神经系统疾病。

## [Polars 2.0 发布，带来重大性能提升](https://pola.rs/posts/release-polars-2/) ⭐️ 8.0/10

Polars 2.0 正式发布，为这款基于 Rust 的 DataFrame 库带来了显著的性能改进和新功能。作为一个主版本号升级，它标志着项目中存在破坏性变更，并代表项目走向成熟的一个重要里程碑。 Polars 已成为 pandas 最具竞争力的开源替代方案之一，此次发布进一步巩固了它与 DuckDB 和 PyArrow 并列在 Python 数据生态中的地位。这些改进将影响在单机上处理大规模数据集的数据科学家、分析师和工程师。 Polars 利用 Rust 的内存安全特性、并行处理能力以及 Apache Arrow 列式存储格式，在多核机器上实现高吞吐量。需要注意的是，原文并未提供完整的技术变更日志，而且正如评论者所提醒的，性能基准测试数据应谨慎解读，因为结果很大程度上取决于具体的工作负载特征。

hackernews · Hacker News \(热门\) · 10月6日 11:59 · [社区讨论](https://news.ycombinator.com/item?id=49977177)

**背景**: DataFrame 库是 Python 和 R 等语言中用于数据处理的核心工具，其中 pandas 长期以来占据主导地位。然而，pandas 最初是为中小规模数据集的单线程内存操作而设计的，随着数据规模增长，这已成为性能瓶颈。Polars 通过使用 Rust 编写、采用 Apache Arrow 的列式内存布局、借助类似数据库引擎的查询优化器来执行查询，以及在 CPU 多个核心间并行处理工作负载来解决这些限制。这使得它对于那些让 pandas 力不从心、但又不需要 Spark 等分布式系统的工作负载特别有吸引力。

## [Reflection 发布 Beam：5010 亿参数开源权重 MoE 模型](https://reflection.ai/blog/introducing-beam) ⭐️ 8.0/10

Reflection AI 发布了 Beam，这是一款稀疏混合专家（MoE）模型，总参数量达 5010 亿，每 token 激活参数量为 230 亿，定位于编码、推理和智能体（agentic）工作负载。该模型在 2.38 万亿 token 上进行了预训练，数据来源于网页和专有授权数据集，并投入了大量强化学习资源。 Beam 在 MoE 架构正成为高效扩展大语言模型标准的当下进入竞争激烈的开源权重模型市场。其聚焦智能体的定位表明，行业正在转向为工具调用和自主任务执行而优化的模型，而非单纯的文本生成。 Beam 的 5010 亿总参数与 230 亿激活参数的比例意味着每次推理仅激活约 4.6%的参数，相比同等能力的稠密模型具有显著的算力效率优势。值得注意的是，社区对比显示 Beam 的架构与 DeepSeek V4.1 Flash 等竞品不同——后者在 prefill 阶段仅激活 80 亿参数，但额外包含 1960 亿的 n-gram/PLE 参数。

hackernews · Hacker News \(热门\) · 10月5日 19:16 · [社区讨论](https://news.ycombinator.com/item?id=49969183)

**背景**: 稀疏混合专家（MoE）架构允许模型拥有极大的总参数量，但每次推理仅激活一小部分参数，相比同等规模的稠密模型大幅降低了推理成本。这种方法因 Mixtral 等模型而广受欢迎，已成为扩展前沿大语言模型的核心方案。智能体 AI（Agentic AI）指的是能够使用工具、API 和推理循环自主执行多步骤任务的 AI 系统，是一个与传统聊天机器人交互截然不同的、日益重要的工作负载类别。Reflection AI 本身是基础模型领域的新晋参与者，这为社区对其长期可持续性的担忧提供了背景。
